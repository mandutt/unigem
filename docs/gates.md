## 최소 표본·신뢰구간 (AM-3, D-022)

판정 전에 최소 표본과 신뢰구간 방법을 선언한다. 표본 부족 시 PASS가 아니라 **INCONCLUSIVE**로 기록한다.
0건 오류 검증에는 rule of three(오류율 95% 상한 ≈ 3/n)를 병기한다.

| 게이트 | 최소 표본 | 신뢰구간 |
|---|---|---|
| G-A3L-R | 220클립(전체) | Clopper-Pearson |
| G-A3 / G-A4 | 층별 cosine 입력 ≥200(길이 구간별) | 최소·분위수 |
| G-B1.5-a | 코퍼스 v2 테스트(틀 단위 분리) | Wilson 95% |
| G-B1.5-b | T1~T3 테스트 표본 | 문장 단위 부트스트랩 |
| G-C1 | 이미지 ≥100(권장 150) | Wilson 95% |
| G-C2 | 평가 발화 ≥300문장 | 부트스트랩(문장 단위) |
| G-C4 | 정상 문장 ≥600 | Clopper-Pearson |
| G-C5 | 슬롯 ≥300(0.5%까지 보려면 ≥600) | Clopper-Pearson |

## 판정 규칙

- 각 보고서는 `PASS / FAIL / INCONCLUSIVE` 중 하나로 끝낸다. FAIL·INCONCLUSIVE도 숨기지 않는다.
- VPS 측정값은 표에 `참고(VPS)`로 표기하고 판정에 쓰지 않는다.
- 서로 다른 호스트의 지연·RAM·처리량을 직접 비교하지 않는다.
