## 최소 표본·신뢰구간 (AM-3, D-022)

판정 전에 최소 표본과 신뢰구간 방법을 선언한다. 표본 부족 시 PASS가 아니라 **INCONCLUSIVE**로 기록한다.
0건 오류 검증에는 rule of three(오류율 95% 상한 ≈ 3/n)를 병기한다.

## 판정 규칙

- 각 보고서는 `PASS / FAIL / INCONCLUSIVE` 중 하나로 끝낸다. FAIL·INCONCLUSIVE도 숨기지 않는다.
- VPS 측정값은 표에 `참고(VPS)`로 표기하고 판정에 쓰지 않는다.
- 서로 다른 호스트의 지연·RAM·처리량을 직접 비교하지 않는다.

## Addendum D 사전 선언 (2026-11-03, 측정 전 등록)

D-β 파일럿은 **연구 트랙**이며 제품 F2 경로를 바꾸지 않는다(D-057). 아래는 결과를 보기 전에 고정한다.

### R-D1 — 병목 가설 지지

- 비교: F-A′, F-B, F-C 중 FLEURS ko **dev** CER(공백 무시) 최저 arm = `best`.
- 상대 개선 = `(CER_FD − CER_best) / CER_FD`, 문장 단위 대응 부트스트랩 95% 구간.
- **지지:** 상대 개선 ≥20% **그리고** 구간 하한 >0.
- **INCONCLUSIVE:** 10% ≤ 상대 개선 <20%, 또는 하한 ≤0. **1회만** 확장(시간 2배 또는 시드 반복).
- **기각:** 상대 개선 <10% → D 중단 권고.
- **주의:** R-D1의 기준은 **F-D arm의 dev CER**(정정 후 0.5909)이지 G-C2의 Notesoop 18.96%가 아니다. 20% 지지는 G-C2(≤15%) 통과와 무관하다. G-C2 판단은 R-D2·스케일업 후 최종 test로 한다.

### R-D2 — 규모 전망

- `best` arm의 학습곡선(H/3, 2H/3, H)을 로그-시간에 선형 적합해 **40시간 외삽 FLEURS ko dev CER**과 예측 구간을 보고한다.
- 점추정 ≤15%면 스케일업 권고, >15%면 중단·보류 권고. **예측 구간을 반드시 병기**하고, 외삽만으로 G-C2를 판정하지 않는다.
- 40h는 학습이 아니라 외삽이며, 실제 스케일업은 별도 저장·호스트 계획과 승인을 요구한다.

### AM-9 — 평가 세트 사용

- 중간 의사결정(arm 선택·조기 종료·중단)에는 **dev만** 쓴다(FLEURS ko dev, AI Hub 유래 holdout).
- test(FLEURS ko test, Zeroth test, Kspon eval_clean)는 **최종 판정에 1회만** 쓴다.
- 이번 라운드에서 이미 사용한 test(G-C2/C-8)는 "사용됨"으로 기록하고, D 트랙의 최종 test 1회는 **새로 선언**한다.
- 위반 시 해당 test 결과는 "탐색적"으로 표기하고 게이트 판정에 쓰지 않는다.

### AM-10 — 병렬 arm

- arm 간 **코드·하이퍼파라미터·시드·데이터 목록을 동일**하게 한다. 달라도 되는 것은 입력 특징의 종류·차원뿐이다.
- arm별 튜닝 금지. 모든 arm 결과(실패·불수렴 포함)를 보고한다.
- arm 선정은 R-D1의 사전 선언 지표로만 한다.
