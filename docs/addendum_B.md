### B-1.1 검토에서 추가로 확인한 사항
- **G-B1.5-a의 적용 범위:** 이 게이트는 "hidden만 보고 토큰을 복원해야 하는" 경로(F5, 생성형 F4)에 해당한다. **편집 태깅형 F4**는 입력 토큰을 이미 알고 있어 표면 보존이 자동이다. Addendum A §A-3.9의 판정표(a 미충족 + b 충족 → 혼합)가 이미 이 구조다. 새 해석이 아니라 **기존 판정표의 확인**이다.
- **T1의 기준선 문제:** BL-1(l00 ±2 선형)은 약한 기준선이다. 오타는 토큰을 희귀 조각으로 쪼개므로, 토큰 빈도·분절 수 같은 단순 어휘 특징만으로도 상당한 성능이 나올 수 있다. l04의 +10.6%p가 이를 넘는지 확인해야 한다.
- **재사용 경제성:** F4/F5가 기존 임베딩 패스의 hidden을 공짜로 재사용한다는 가정은 메모리 경로에서 성립하지 않을 수 있다. 저장 임베딩은 요약된 최종 텍스트에서 만들어지고, 맞춤법·요약의 입력은 원문이다. **절감되는 것은 연산이 아니라 상주 RAM(추가 모델 없음)**이다. 원문에 대한 EG2 패스 1회(512토큰 p50 540ms)가 추가되는 것은 감수한다. 이 가정을 문서와 보고서에 명시한다.
- **보고서 일관성 점검 필요:** 보고서의 B1.5-1 결과 표(l00 test 0.8856, 전체어휘 4,096표본 0.9165)가 서로 다른 모집단에서 계산되었는지 확인한다.

## B-3. R1: G-B1.5-a 정정 재측정

### B-3.1 상태 재분류
- `gates.md`의 G-B1.5-a를 **"INCONCLUSIVE(프로토콜 미준수)"**로 정정한다. 근거: B1.5-1이 Addendum A §A-3.4의 다음 요구를 이행하지 않았다: 학습률 탐색, 수렴 확인(조기 종료), 학습 정확도 병기, 전체 어휘·전체 테스트 평가, span exact 측정.
- 이전 결과(l00 0.8856, l04 0.8175, last 0.4438)는 "최적화 부족 가능성이 있는 예비 결과"로 보존한다.
- 보고서의 epoch 수·스텝 수·학습률 기록을 확인해 사실 여부를 보고한다(보고서상 epoch 3, 약 95 스텝).

### B-3.2 재측정 사양

**(1) 진단(학습 없음):** 각 층 특징으로 **임베딩 테이블 최근접 이웃**(코사인, 전체 어휘 262,144)을 직접 수행해 정확도를 보고한다. l00에서 이 값이 이미 높으면(예: ≥ 95%) 이전 프로브의 낮은 값은 최적화 문제로 확정된다.

**(2) 폐쇄형 프로브(주 측정):** `W = argmin ||H·W − E_y||² + λ||W||²`(릿지 회귀, `H`: 층 특징 `[N,512]`, `E_y`: 정답 토큰 임베딩). λ는 검증 분할에서 선택. 평가는 **전체 어휘 코사인 최근접**을 **전체 테스트 분할**에서 수행(청크 계산). SGD 최적화 문제가 없고 결정적이다.

**(3) 경사 프로브 v2.1(보조):** 로짓 = 코사인 유사도 × 학습 가능한 온도. `W`는 단위행렬로 초기화. 후보 소프트맥스는 Addendum A §A-3.4와 같다. AdamW, **lr {1e-4, 3e-4, 1e-3, 3e-3}**, 최대 100 epoch, 검증 정확도가 10 epoch 개선되지 않으면 종료, 시드 3회. **학습·검증·테스트 정확도를 모두 보고**하고 수렴 곡선 데이터를 저장한다.

**(4) 조합 층:** `l00 ⊕ l04`(1024 → 512 투영)를 후보에 추가한다.

**(5) 필수 지표 (95% 구간 포함):** 전체 토큰 정확도, 숫자, 언어별(ko/en/ja/zh), **학습에 등장한 토큰 / 등장하지 않은 토큰 분리**, **식별자·숫자 span exact**(문자 오프셋 기준, 실제 식별자 세트와 틀 단위 분리 테스트, 범주별 n 표기, n < 30인 범주는 참고만), 문자 단위 편집거리.

**(6) 판정:** 임계값은 **불변**(토큰 ≥ 98%, 식별자·숫자 span exact ≥ 95%, 점추정 충족 + Wilson 하한이 기준 −5%p 이상). 결과는 층별로 보고하고, 후보 층 L의 PASS/FAIL을 판정한다.

**(7) 오류 방지 점검:** l00의 **학습 정확도가 수렴 후에도 99% 미만이면** 프로브 설계 결함으로 보고 판정 전에 원인을 먼저 규명한다.

### B-3.3 해석 범위 기록
- G-B1.5-a는 **hidden → 디코더 결합(F5, 생성형 F4)** 가능성의 게이트이며, **편집 태깅형 F4의 입력 선택**에는 직접 적용되지 않는다(§B-1.1). 이는 Addendum A §A-3.9의 판정표와 일치하므로 `decisions.md`에 "확인"으로 기록한다.

## B-4. R2: G-B1.5-b 정정 재판정

### B-4.1 상태 재분류
- T3: **INVALID-MEASUREMENT(VR-1 위반, BL-1 100%)**.
- T2: 유효, **FAIL 유지**(+1.87%p, 기준 +3%p). 교체하지 않는다.
- T1: 통과이나 양성 102개로 작아 **재현 확인이 필요**.
- G-B1.5-b: **INCONCLUSIVE**(유효 과제 2개 중 1개 통과, T3 교체 후 재판정).

### B-4.2 T3′ (교체 과제, 사전 선언)
- **자연 문장 기반.** 공개 한국어 자연 문장(FLEURS ko, 구어체 공개 텍스트)에서 혼동쌍의 정답 형태가 **그대로 등장하는** 문장을 찾아 라벨은 원문의 형태로 두고, 음성 사례는 혼동 형태로 치환해 만든다(외부 API 사용 금지).
- **혼동 유형 ≥ 5종:** 되/돼, 안/않, 로서/로써, 던/든, 낫/낳/났 등. 유형별 **테스트 ≥ 120**, 전체 테스트 ≥ 600.
- **분할:** 문장 그룹 단위 70/15/15, 유형별 균형.
- **유효성:** VR-1을 적용한다. 다시 BL-0 또는 BL-1 ≥ 98%이면 **T3′도 무효**이고 더 재설계하지 않는다(1회 한정). 이 경우 G-B1.5-b는 INCONCLUSIVE로 두고 B-6(F4 파일럿)의 결과로 판단한다(B-12).
- 사전 선언 문서(`gates.md`)를 데이터 생성 **전에** 작성하고 해시를 남긴다.

### B-4.3 T1 확장 재현 (사전 선언)
- 신규 시드·신규 문장으로 오타 쌍 **≥ 1,500쌍**을 생성한다(코퍼스 v2의 학습·테스트와 문장 중복 금지). 테스트 양성 토큰 **≥ 300**.
- 기준선: BL-0, BL-1에 더해 **BL-2(어휘 특징 기준선)**: BL-1 특징 + 토큰 훈련 빈도(log), 단어 내 토큰 분절 수, 숫자·라틴 여부, 토큰 문자열의 문자 n-gram 해시(1~2). 모든 모델은 동일한 용량(선형 또는 1은닉층 MLP)과 예산으로 학습한다.
- 판정(사전 선언): **ΔF1(l04 − BL-1) ≥ +3%p, 문장 클러스터 부트스트랩 95% 하한 > 0**이면 T1 재현 PASS. BL-2 대비 차이는 **보조 보고**한다(PASS 조건 아님, B-6에서 본 판정에 사용).

### B-4.4 T2′ (탐색적)
- 문장의 공백 일부(예: 무작위 30% 제거 + 10% 삽입)만 변형한 현실적 분포로 재측정한다. **탐색적 결과**이며 G-B1.5-b 판정에는 쓰지 않는다.

### B-4.5 G-B1.5-b 재판정 규칙 (임계값 불변)
- 유효 3개 과제(T1 확장, T2 기존, T3′) 중 **2개 이상이 ΔF1/Δ정확도 ≥ +3%p, 부트스트랩 하한 > 0**이면 PASS. 그렇지 않으면 FAIL. T3′가 무효이면 INCONCLUSIVE.
- 다중 비교: 과제가 3개이고 "2/3" 규칙이 이미 보수적이므로 추가 보정은 쓰지 않는다. 대신 효과 크기와 구간을 모두 보고한다.

## B-6. P1: F4 파일럿 (C4 선행, 결정적 실험)

**목적:** "EG2 텍스트 hidden(l04 등)이 맞춤법 오류 탐지에서 **강한 비-EG2 기준선**보다 나은가"를 현실적인 데이터에서 직접 판정한다. 이 결과가 B-12의 주된 판정 근거다.

### B-6.1 데이터 (P0)
- **정상 문장 ≥ 1,200**: 공개 자연 문장(FLEURS ko, 구어체 공개 텍스트), 코퍼스 v2의 테스트와 문장 중복 금지.
- **오류 문장 ≥ 2,000**: 정상 문장에서 규칙 합성. 문장당 오류 1~3개. 유형 혼합(비율은 보고서에 기록): 띄어쓰기 부분 오류(일부 경계만 제거·삽입), 자모 오타(받침·모음 혼동, 2벌식 자판 인접), 조사·어미 혼동(되/돼, 안/않 등), 영문·식별자 혼합 문장의 오타, 다중 오류.
- 라벨: 토큰 단위 "오류 span에 속함". 분할은 문장 그룹 70/15/15, **혼동쌍·오류 규칙 일부는 테스트 전용으로 홀드아웃**한다.
- **테스트 양성 토큰 ≥ 300**, 테스트 정상 문장 ≥ 600(G-C4와 같은 규모, rule of three 기준).
- 공개 한국어 교정 코퍼스가 C-D0에서 확인되면 추가 평가 세트로 병행하고, 접근에 신청이 필요하면 사용자에게 요청 사항을 보고한다.

### B-6.2 비교 모델 (동일 용량·동일 예산)

| ID | 입력 | 설명 |

| H1b | BL-1 ⊕ l00 ⊕ l04 ⊕ 선택 층 | 다층 후보 |

- 시드 3회.

### B-6.3 지표
- 토큰 단위 AUPRC, F1(임계값은 검증에서 선택해 테스트에 고정), 문장 단위 오류 존재 탐지 정밀도(재현율 0.8 고정).
- **정상 문장 오탐률**(재현율 0.8 운영점에서 정상 문장에 대한 오탐 비율).
- **데이터 효율 곡선:** 학습 데이터 5% / 10% / 25% / 50% / 100%.
- 지연: 상주 EG2 패스(64/128/512토큰 p50/p95, 로컬, 스레드 6)와 헤드 추론 시간.
- 모든 비율·차이에 95% 구간(문장 클러스터 부트스트랩).

### B-6.4 판정 (사전 선언, 이 문서로 등록)
- **VR-1 적용:** 모든 기준선의 AUPRC가 ≥ 98%이면 파일럿 무효.
- **F4-EG2 채택 후보 PASS:** H1 또는 H1b가 H2~H5 중 **최고 성능 기준선**을 AUPRC로 (a) 100% 데이터에서 **+3%p 이상, 부트스트랩 하한 > 0**이고, (b) **≤ 10% 데이터에서 +5%p 이상**이며, (c) 정상 문장 오탐률이 최고 기준선보다 나쁘지 않을 때.
- **FAIL:** 조건 (a)~(c) 중 하나라도 미충족이고, 점추정이 기준 미만이거나 부트스트랩 95% 구간 상한이 기준 미만일 때.
- **INCONCLUSIVE:** 점추정은 기준 이상이나 구간 하한이 0 이하(또는 기준 미만에 걸림)일 때 → **1회만** 테스트 세트를 확대해 재측정한다.
- 근거: EG2 hidden이 상주 모델의 이점(추가 모델 없음)을 가지므로, 동급 비용의 경량 스크래치 모델을 **유의하게** 넘어야 정당화된다. 데이터 효율 조건은 "사전학습된 문맥화의 가치"를 직접 본다.

## B-7. L1: G-A3L-R 후속 (운영 교체 보류)

1. **판정 유지:** G-A3L-R은 **FAIL**. PASS-R(§A-2.3) 조건도 불충족(신규만 틀림 3 > 0, 확신 오판 +2). 예외·완화 없음. `decisions.md`에 기록.
2. **같은 220클립으로 재판정하지 않는다.** 통과를 찾는 반복은 허용하지 않는다. 추가 근거가 필요하면 **독립 신규 클립**(예: 같은 언어군의 dev 분할, n ≥ 500)을 별도 세트로 사전 등록해 사용한다.
3. **원인 분석(필수):**
   - 불일치 4건과 확신 오판 +2건의 클립, 정답 라벨, 기존/신규 argmax·margin, 언어쌍, 소스(FLEURS/실환경).
   - 기존 운영 그래프와 신규 Q8 그래프의 pooled 임베딩 코사인 분포(220클립), margin 분포 비교.
   - FP32 연구용 그래프에서도 같은 분석을 수행(참고).
4. **구조적 해결 가능성(우선 검토):** **출력 탭 추가형 개조.** 기존 운영 그래프를 **수정하지 않고 복사본**을 만들어 중간 텐서를 추가 출력으로 노출(그래프 수술). 이러면 pooled 출력은 기존과 같은 커널·같은 양자화를 거치므로 **정의상 동일**하고, STT 특징도 배포 그래프와 같은 분포가 된다(G-A3S·G-C2a 문제도 감소).
   - 확인 사항: 운영 그래프가 최적화·융합을 거쳐 저장되어 중간 텐서가 사라졌는지, 사라졌다면 **운영 양자화 절차를 그대로 재현**해 탭을 넣을 수 있는지, 기존 양자화 방법(레시피)이 코드로 재현 가능한지.
   - 판정: 탭 추가 그래프의 pooled 출력과 기존 운영 출력의 최대 절대 오차와 220클립 argmax 일치율을 보고한다. **같은 판정 규칙(G-A3L-R)을 이 후보 그래프에 적용**해 PASS/FAIL을 판정한다.
5. **잠정 운영:** 기존 LID 그래프는 그대로 두고 신규 다중 출력 그래프는 신규 헤드(F2/F3/F4)에만 사용한다. 두 그래프의 **상주 RAM 이중 계상**(오디오 타워 Q8 크기)을 추정해 보고한다.

## B-10. 병렬 트랙: C2-A1과 C1 파일럿

### B-10.1 C2-A1: Notesoop CER 기준선 (`vps-3` + 로컬)
- **평가 세트:** Zeroth-Korean의 **test 분할만**과 FLEURS ko test. **전체 9.6GB를 내려받지 않는다**(VPS 디스크 20GB, 여유 2GB 가드). 분할 단위 또는 스트리밍으로 test만 확보한다.
- **비교 대상:** komixv2, whisper-turbo(한국어 강제), Notesoop(greedy, 가능하면 +KenLM). 같은 정규화를 쓴다(구두점 제거, 띄어쓰기 영향 분리, CER 주지표 + WER 병기). 문장 단위 부트스트랩 95% 구간.
- **G-C2 적용:** FLEURS ko test에서 greedy CER ≤ 15% 기준을 후보 reader에 동일하게 적용한다.
- **환경:** CER은 VPS 가능, RTF·RAM은 로컬 CPU에서 측정(판정용). Notesoop의 입력 특징 지점(오디오 타워 → lm.norm → projection[:256] → L2, 256d bf16)을 우리 ONNX로 재현할 수 있는지는 **G-A3S/G-C2a(승인 대기 제안 게이트)**로 별도 측정한다.
- **미검증 항목 해소:** 오디오 Q8 카나리(VPS 원본 그래프 부재)를 해결한다. 로컬에서 만든 Q8 오디오 그래프를 SHA256 검증과 이어받기 가능한 방식으로 `eg2-1`에 배포해 고정 입력 20~50개로 비교한다.
- **산출물:** `reports/C2_A1_cer.md`, `reports/A9_audio_canary.md`

### B-10.2 C1 파일럿 (PyTorch, `vps-5`)
- **ONNX export 이전에 정확도부터 판정한다.** 텍스트+비전(440M) 구성을 **PyTorch FP32**로 실행해 이모지 검색 정확도(G-C1: top-1 ≥ 70%, top-3 ≥ 85%, margin 통과 후 부적절 태그 ≤ 5%, 이미지 ≥ 100장, Wilson 95%)를 측정한다. 정확도는 하드웨어와 무관하므로 PyTorch 결과로 G-C1 판정이 가능하다. 지연·RAM은 ONNX 이후 로컬에서 측정한다.
- **프로토콜:** plan v0.5 C1 그대로(공개 이미지, 후보 풀 혼합·출처 숨김 라벨링, VLM은 후보 생성원일 뿐). Qwen3-VL-2B 라이선스는 이 단계에서 확인해 보고한다.
- **ONNX export는 이 파일럿의 정확도가 G-C1을 충족한 뒤**에 착수한다. 착수 시에는 `dynamo + 정적 shape + optimize=False` 조합과 `pixel_position_ids` 입력을 우선 시도하고, 실패·타임아웃은 1회 기록 후 보고한다.
- 한 호스트에 무거운 job 1개 원칙을 지키고 VLM job은 단독 실행한다.

## B-12. CP2′ 판정표 (사전 선언)

R1(G-B1.5-a)·R2(G-B1.5-b)·P1(F4 파일럿) 보고서가 모두 제출된 뒤 사용자가 CP2′에서 결정한다. Hermes는 아래 표에 따라 **권고**만 제시한다.

| R2: G-B1.5-b | P1: F4 파일럿 | 권고 |
|---|---|---|
| **유효 FAIL** | (무관) | 사전 등록대로 **EG2 텍스트 hidden 폐기**(F4/F5). F4는 규칙+경량 헤드, F5는 네이티브 T5Gemma 2 |
| PASS 또는 INCONCLUSIVE | **PASS** | **F4만 EG2 l04(필요 시 l00 병합) 헤드 채택 후보.** F5는 네이티브(arm A1). EG2→디코더 결합은 R1(a)과 H4′가 모두 PASS인 경우에만 별도 검토 |
| PASS 또는 INCONCLUSIVE | **FAIL** | EG2 텍스트 hidden 폐기. P1이 더 엄격한 기준이므로 P1이 우선 |
| PASS 또는 INCONCLUSIVE | **INCONCLUSIVE** | P1을 1회 확대 재측정 후 위 행으로 이동. 그래도 불명확하면 사용자 결정 |

- F1·F2·F3은 텍스트 hidden을 쓰지 않으므로 이 판정과 무관하다.
- R1(a)은 hidden→디코더 결합(F5/생성형 F4)의 선행 조건으로만 쓴다.
