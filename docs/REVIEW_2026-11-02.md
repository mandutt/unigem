## 1. 프로젝트 개요

메모리 시스템에 항상 상주하는 **EmbeddingGemma 2(EG2)** 하나를 인코더로 재사용하고, 그 위에 작업별 경량 헤드를 얹어 다음을 대형 모델 없이 수행할 수 있는지 실측 검증한다.

| # | 기능 | 방식(가설) |
|---|---|---|
| F1 | 오디오 언어 판정 | 프로토타입 + margin (기존 운영) |
| F2 | 한국어 STT | 동결 EG2 + CTC reader (Notesoop-STT-Ko-v1 평가 우선) |
| F3 | 비전 태깅 | 화면 → 유사 이모지 검색 → 이모지 명칭 태그 |
| F4 | 맞춤법 검사·교정 | 규칙 + 디코더 재순위 또는 edit 태깅 |
| F5 | 메모리용 요약 | 디코더 생성 + 슬롯 검증기 |
| F6 | STT 후처리 | CTC 출력 → 디코더 교정 |

### 불변 조건 (문서 §0, §3)

- 목표 하드웨어: **로컬 PC** (Windows 11, Ryzen 5 7600 6C/12T, 15.6GB, GPU 없음, ONNX Runtime CPU EP, **Q8만**)

## 7. 현재 쟁점 (검토가 필요한 지점)

### 7.1 G-A3L FAIL을 예외 승인한 것

- 43/44 = 97.7%로 사전등록 임계값(99%) 미달. 유일한 불일치는 id↔ms 초근접 경합(margin <0.01), 확신 오판 0.
- "실질 회귀가 아니라 게이트 정의 문제"로 판단해 **FAIL 기록을 유지한 채 1건만 예외 승인**했다.
- 대안: 220클립으로 확대 재측정(비용 발생), 게이트를 그룹 기준으로 재정의(사전등록 변경).

### 7.2 G-B1 해석

- 토큰 id 복원 게이트를 **l00(최상위 층)이 통과**했다. 그러나 l00은 맥락이 약해 F4 edit 태깅에 그대로 쓰기엔 부적합할 수 있다.
- 중간층 l04는 전체 94.5%, span 85.3%로 미달.
- 현재 선택지: (A) l00 + 정규식 가드, (B) l04 채택 + 임계값 재협의, (C) EG2 hidden 폐기.
- 추가 쟁점: **식별자 지표를 토큰 단위에서 span 단위로 재정의한 것**이 사전등록 위반인지, 지표 결함 수정인지.

### 7.3 오디오 FP32 그래프의 정적 shape

- 동적 shape export가 불가능해 500/1600/3000 mel 3종을 운용한다. 런타임은 가장 가까운 긴 그래프에 zero-pad + mask.
- 우려: 패딩 계산 낭비, 경계 효과, 30초 초과 오디오 처리 정책 미정.

### 7.4 VPS 정합 검증의 범위

- 실제 EG2 그래프가 아니라 **소형 합성 ONNX**로 호스트 간 cosine을 비교했다(cos 1.0).
- EG2 Q8/FP32 그래프를 5대에 배포해 재검증하지는 않았다(그래프 680MB~1.2GB 전송 비용).

### 7.5 B1 코퍼스의 대표성

- 1,050문장, 10개 언어 각 60문장. FLEURS test 일부만 사용.
