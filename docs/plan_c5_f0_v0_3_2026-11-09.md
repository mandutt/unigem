## 3. Definitions

- EG2 layer19 h, 512 dims; M prefix K=753.
- Adapter: 512→512, Linear/GELU/Linear/LayerNorm; random init.
- Decoder LoRA: 64 mT5 q/k/v/o modules; r8 alpha16 dropout .05.
- Training: AdamW, wd .01, adapter lr 1e-3, LoRA lr 1e-4, 100 updates, batch 1, train20[step%20], clip 1.0, base decoder eval.
- M: M_POS_MEAN/M_NORM, K=753, 15 common, 120 records/cell/seed.
- Signal: donor-crop K=min(len(real),len(donor)), 20 val docs, 5 donors.
- Thresholds/seed/donor/step/LR: frozen Phase 6 values; no changes.

## 4. RNG and init contract (F0-only)

F0 must not modify Phase 6 `build_arm`. New F0 builder:

```text
load_base()
torch.manual_seed(seed)
adapter = Adapter(512,512) if cell.adapter else None
torch.manual_seed(seed ^ LORA_SEED_XOR)   # always, adapter-independent
lora_names = attach_decoder_lora_mt5(model) if cell.lora else []
```

- `LORA_SEED_XOR = 0x5EED10A5` (fixed constant; exact value in code).
- E01 and E11 call the LoRA seed reset identically.
- E10 and E11 call the adapter seed identically.
- Assertions:
  - `sha256(state_dict(lora_A/lora_B))` E01 == E11 at init.
  - `sha256(state_dict(adapter))` E10 == E11 at init.
  - E00/E01 have no adapter; E00/E10 have 0 LoRA modules.
- `init_state_sha256` written per cell/seed to artifact.
- Phase 6 `build_arm` remains unchanged; F0 has separate builder.

## 6. Primary endpoint

### 6.1 Source

- Primary source: **final checkpoint donor-crop eval** (`unit.final.per_doc`).
- 20 val docs, 5 donors, donor-crop `K=min(len(real),len(donor))`.
- 15 common docs for paired inference.
- Phase 7 records are **diagnostic only**, not primary.
- Step0 is diagnostic; final is primary.

### 6.2 Cell delta

For cell c, seed s, doc d:

```text
delta_c(s,d) = mean_donor( CE_wrong_donor - CE_real )
```

- copy and full endpoints separately.
- per-doc seed average: `delta_c(d) = mean_s delta_c(s,d)`.

### 6.3 Primary contrast

```text
D(d) = delta_E01(d) - delta_E11(d)     # paired, same 15 docs
mean_D = mean_d D(d)
CI_D = bootstrap_paired_v2(D, n_boot=1000, seed=20261109)
```

- Primary positive: `mean_D > 0 AND CI_D.lower > 0`.
- Copy is primary; full is secondary.
- No per-cell significance conjunction for primary.

### 6.4 Cell descriptors (secondary)

- `E01_SIGNAL_COPY`: mean(delta_E01) ≥ .05, CI lower >0, 2/3 seeds >0.
- `E11_SIGNAL_COPY`: same for E11.
- full analogous.
- These are descriptors, not the primary decision.

### 6.5 Practical null

```text
E01 ≈ E11  iff  CI_D contains 0 AND |mean_D| < .05
```

- `uncertain` if CI contains 0 but |mean_D| ≥ .05.
- No equality claim from non-significance.

### 6.6 Missing data

- Exactly 15 common docs required.
- Exactly 3 seeds required.
- A doc/seed with missing copy endpoint is NA.
- No 15→14 substitution; no “2 of available”.
- If <15 or <3 seeds: `NOT_EVALUABLE`.

## 7. Interpretation (pre-registered)

Let `PROTOCOL_VALID` = D0/D1/R mechanics pass + 15 docs + 3 seeds + M evaluable.

- **E01+ / E11− / CI_D.lower >0**: adapter-associated signal loss supported under this configuration.
- **E01− / E11−**: this configured EG2-raw→mT5-decoder route does not show donor-specific signal. **Not** proof that EG2 features lack information. Track decision separate.
- **E01+ / E11+**: adapter not necessary under this regime; check replication/anomaly, not H3.
- **E01 ≈ E11**: adapter effect not supported in this assay.
- **E01− / E11+**: unexpected; replication/anomaly; no causal claim.
- `ROUTE_STOP` only if `PROTOCOL_VALID` AND both E01/E11 fail copy and full on 3/3 seeds AND `CI_D` not >0.
- If not `PROTOCOL_VALID`: `NOT_EVALUABLE`, not route STOP.
- No positive result uniquely proves adapter architecture; no negative proves feature insufficiency.
- F0 does not retroactively change Phase 6 negative or B0-B non-approval.
