## 3. 084a — URL-only measurement baseline

### 3.1 URL span extraction

URL raw span은 다음 규칙으로 추출한다.

- 시작: `http://` 또는 `https://`.
- URL 문자: ASCII URL grammar
  `A-Z a-z 0-9 - . _ ~ : / ? # [ ] @ ! $ & ' ( ) * + , ; = %`
- 종료:
  - whitespace
  - `< > " '`
  - Hangul `[가-힣]`
  - unmatched closing bracket/quote
- **trailing Hangul particle은 URL에 포함하지 않는다.**
  - `https://coronamap.site에서` → URL은 `https://coronamap.site`, `에서`는 별도.
- URL raw span과 normalized span을 모두 기록한다.

### 3.2 URL boundary / punctuation

URL 끝의 `.`, `,`, `;`, `:`, `!`, `?`, `)`, `]`, `}`는 문장부호일 수도, URL 내용일 수도 있다.

- **자동 strip 금지**.
- 다음 중 하나로 확정 가능할 때만 boundary를 결정한다.
  1. URL 문법상 명백히 unbalanced closing delimiter
  2. source-side wrap이 attest됨
  3. URL immediately followed by whitespace/end이고, 같은 string의 exact URL이 source에 존재
- 판정 불가면 **unresolved**로 기록하고 v1 prefix로 fallback하지 않는다.
- `http://fine.fss.`는 **unresolved**.
- trailing slash는 보존한다.
  - `https://x.com/` ≠ `https://x.com` (명시적 정책).
- percent-encoding:
  - `%2F`와 `%2f`는 **hex case만 비교 시 uppercase로 정규화**.
  - percent-decoding은 하지 않는다.
  - `+`를 space로 바꾸지 않는다.
- scheme/host만 lowercase.
- path/query/fragment case, comma, escape, fragment를 보존한다.

### 3.3 Source-side wrap candidate

source-side wrap은 deterministic grammar로 판정한다.

```text
URL raw token이 line break 직전에 '.', '/', '-', '_'로 끝난다.
line break 직후에 optional spaces/tabs만 있고 blank line은 없다.
continuation은 ASCII URL character로 시작한다.
continuation에 Hangul이 없다.
joined string이 URL grammar를 만족한다.
```

- 위 조건을 만족하면 **source-side candidate**로 기록한다.
- candidate는 원문 span, line break 위치, continuation, join 이유를 저장한다.
- 하나의 line break에 multiple continuation 가능성이 있거나 punctuation이 ambiguous하면 **unresolved**.
- source-side candidate는 “source가 스스로 attest한다”는 표현을 쓰지 않는다. **deterministic candidate**다.

### 3.4 Summary-side attested join

summary-side join은 source-side candidate와 일치할 때만 허용한다.

```text
summary wrap candidate를 join한 URL이
source-side resolved URL과 strict canonicalization에서 동일할 때만 join.
```

- summary만 보고 suffix를 추측하지 않는다.
- summary join이 source URL과 일치하지 않으면 **unresolved**.
- source와 summary가 **둘 다 wrapped**인 경우도 각각 candidate를 만든 뒤 비교한다.
- 02742 golden:
  - source: `http://coronamap.\n site`
  - 1,940 summary: wrapped
  - 2,586 summary: joined
  - 084a는 세 경우 모두 `http://coronamap.site`로 attest.
- `http://fine.fss.`는 source candidate가 ambiguous이므로 unresolved.
- `04909` trailing slash는 exact policy로 unresolved 또는 exact match; 자동 strip 금지.

### 3.5 URL over-join negatives

- URL 뒤 line break + 일반 영어 소문자 문장 시작 → join 금지.
- URL 뒤 line break + Hangul → join 금지.
- URL 뒤 blank line → join 금지.
- source에 없는 suffix를 summary가 완성 → join 금지.
- `https://a.com/.` + `the next` → join 금지.
- percent-escape/trailing slash/case 차이 → 별도 test.

### 3.6 084a invariants

- v1 `eval/slot_verify.py`는 byte-identical.
- 084a는 URL span 외의 slot extraction semantics를 바꾸지 않는다.
- URL span으로 소비된 text의 digit/path fragment가 다른 slot으로 중복 추출되지 않도록 한다.
- **084b diagnostic은 084a의 `grounded`, counts, ranking을 바꿀 수 없다.**

## 8. Human 50 protocol

### 8.1 Sample

- same 50 unique val docs.
- 4 arms: pilot300, 1,293, 1,940, 2,586.
- **400 ratings** = 50 docs × 4 arms × 2 raters.
- stratified:
  - 20 targeted: 04951, 04709, 03978, 02742, 03801, 2,586 slot-free with target slots, top slot losses, lowest F1.
  - 30 random from remaining val, seed fixed.
- 16/161 train-prefix-sharing documents: flag; random stratum sensitivity; not silently pooled.
- targeted and random reported separately.
- no naive 50-row bootstrap over stratified sample.

### 8.2 Blind

- randomize arm labels and order per document.
- hide checkpoint identity.
- length confound: pilot300 gen_len 248.3 vs full 190–200; record, do not use length as label.
- 2 raters; third arbitration on disagreement.

### 8.3 Rubric

Per output 0–4 adequacy:

- 0: wrong/unusable
- 1: major essential omissions
- 2: correct gist, minor omissions
- 3: essential facts mostly retained
- 4: essential facts retained, no material omission

별도:
- unsupported/extrinsic assertion (critical/noncritical)
- wrong entity/relation/negation
- wrong unit/qualifier
- omission of key fact
- fluency/repetition
- memory utility

### 8.4 Primary contrast

- **2,586 vs pilot300**: paired source-grounded adequacy, unsupported critical content, key-fact omission.
- **2,586 vs 1,293**: named secondary sensitivity.
- **1,940 vs pilot300 / 2,586**: exploratory quality contrast; cannot make 1,940 eligible.

### 8.5 Decision rule (사전등록)

- 2,586이 pilot300 대비:
  - confirmed critical unsupported assertion에서 **non-inferior** (0 vs 0, or no additional confirmed critical error)
  - key-fact omission에서 **acceptable** (predefined discordant-pair limit)
  - paired adequacy lower 95% bound ≥ **−0.25** (proposal; user approval needed)
- 하나라도 실패/INCONCLUSIVE:
  - `candidate_status=NO_ELIGIBLE_CHECKPOINT`
  - pilot300 fallback
  - test 163 seal
- 1,940이 quality에서 우수해도 **eligibility를 바꾸지 않는다**; 별도 policy decision으로만 다룬다.
- human 50 완료만으로 test를 열지 않는다.
