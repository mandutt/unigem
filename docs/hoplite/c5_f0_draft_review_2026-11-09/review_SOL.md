## Q1. 2×2 validity

- **판정: conditional.** E01 versus E11 is the right primary *training-regime* comparison, but “LoRA fixed” must mean more than the same module count. It does not hold the learned decoder weights fixed or isolate a structural mechanism.
- **근거:**
  - F0 §§2–2.1 specify E00 = raw/no LoRA/0 updates; E10 = adapter/no LoRA/100; E01 = raw/LoRA/100; E11 = adapter/LoRA/100. Comparing E01 with E11 removes the two-factor F0-versus-F error identified in §0. Both primary cells use EG2 and 64 decoder LoRA modules, r=8, alpha=16, dropout=.05. A positive paired difference therefore addresses adding the **whole trained adapter regime** with decoder LoRA enabled.
  - However, v1.0.11 §§2.5.4, 2.7 and `runner/c5_pm_phase6.py:142–155` construct a random adapter **before** initializing LoRA, with no intervening reseed. Simply omitting that construction for E01 changes the RNG state used for LoRA A. B starts at zero, so initial effective LoRA output is zero in both arms, but subsequent gradients depend on A. Equal seed labels and 64 equal module names are not matched initial LoRA tensors. The draft does not resolve this. Nor are final LoRA weights identical: they co-adapt to different memory paths. Shared gradient clipping at 1.0 also permits optimization coupling with the adapter gradients.
  - The adapter adds **526,336 parameters**, has two 512→512 Linear layers, GELU and LayerNorm, and is trained at **1e-3**, versus LoRA **1e-4** (v1.0.11 §2.2). These are components of the intervention, not independently identified causes. F0 §0 appropriately acknowledges the capacity and 10× LR differences; calling the resulting contrast “adapter presence alone” must not erase them.
  - E10−E00 estimates learning/insertion of the adapter relative to a frozen raw baseline, not an architecture-only effect at equal adaptation. E11−E10 measures adding LoRA within the adapter regime. E01−E10 changes both factors and is not clean, as §2 already says. A difference-in-differences `(E11−E01)−(E10−E00)` can be reported as a regime interaction, but not as a training-independent adapter×LoRA mechanism. E00 is legitimately a no-op treatment, not a missing fourth trained unit; executing 100 empty updates would add no scientific control.
  - F0 §2.1's table-sized “753×512” memory must not become a universal training/generation truncation. Under §§3–4 and v1.0.11 §2.3, **753 is M-only**; signal uses actual per-donor minimum lengths, with all 20 validation documents evaluated and 15 common documents selected for the primary summary.
- **다음 단계:**
  1. Before freeze, specify matched E01/E11 initial LoRA A/B tensors and training RNG behavior, fresh base state, modes, parameter groups, order and lengths. Record initialization hashes. Resolve RNG consumption prospectively in the new F0 contract while preserving the listed seeds and frozen numerical hyperparameters; do not silently alter the historical Phase 6 contract or results.
  2. Keep the four-cell primary design; retain E00 and record step0 for all cells to expose insertion versus learning effects. No extra trained primary cell is essential for the narrow regime question. Rerun E11 within the approved F0 implementation rather than substituting an unmatched historical L result.
  3. For structural claims, require separately preregistered controls: e.g. a frozen random adapter versus its trained counterpart, or matched normalization ablations. Capacity/LR controls and shared-decoder interventions are follow-up questions, not additions quietly folded into this primary contrast.

## Q3. H3: LayerNorm, projection and residual

- **판정: conditional.** Agree with F0 §1 H3 keeping **all three** outside the primary 2×2. Disagree that these arms as written identify the adapter's LayerNorm cause or guarantee identity preservation.
- **근거:**
  - `E01-LN` compares raw memory with normalized raw memory, not the actual adapter's LayerNorm with that layer removed. The actual path is `Linear→GELU→Linear→LayerNorm` (v1.0.11 §2.5.4). LN after two trained Linear layers sees a different input distribution and includes learned affine parameters. A fixed LN on raw features tests normalization sensitivity, not mediation by the trained adapter LN. “Fixed” also needs normalized axis, epsilon, affine values and training status. With gamma=1/beta=0, tokenwise LN still removes token mean and scale; it is not an identity transform.
  - A **512×512 orthogonal** projection is invertible and preserves Euclidean norms and pair distances. It can nevertheless destroy compatibility with a frozen pretrained decoder basis. One frozen random rotation tests coordinate/alignment sensitivity, not general information loss or learned projection quality. If “projection” means lower rank, the information-preservation statement no longer holds; §1 gives no rank, matrix or initialization contract.
  - `x + Adapter(x)` contains an identity **skip**, not a guarantee of identity behavior or retained information. It equals x only when the residual branch is zero; its Jacobian is `I + J_Adapter` and can be singular. An unrestricted branch can cancel or dominate x. The proposed random full-strength branch is not identity-initialized merely because the skip coefficient is 1. A zero-output initialization or an explicitly gated branch can give identity at step0, not guarantee it after learning.
  - Adding these choices to primary inference after observing E01/E11 would introduce design selection and multiple comparisons, and their compute is absent from F0 §5's 300/900 updates.
- **다음 단계:**
  1. Retain no H3 arm in the primary four-cell execution or primary success decision. Give H3 its own preregistration, approval, endpoint family and compute envelope.
  2. For a LayerNorm question, preregister matched pre-LN mappings with/without LN and account for retraining/co-adaptation; a frozen-checkpoint removal is an intervention with a distribution shift, not by itself proof of the training mechanism. Keep raw+fixed-LN only as a clearly labeled sensitivity diagnostic.
  3. Specify a full-rank orthogonal matrix and its fixed identity/hash if used; specify residual initialization, scaling/gating and which parameters train. Replace “identity-preserving” with “identity-skip; identity-initialized only if the branch is initially zero.” None of these changes is implemented here.
