## 1. 질문

> **LoRA initialization을 match한 상태에서 adapter 유무가 EG2 donor-specific signal을 바꾸는가?**

## 2. Cells

| cell | memory | adapter | decoder LoRA | updates | 역할 |
|---|---|---|---|---|---|
| E00 | EG2 raw 753×512 | none | none | 0 | eval-only baseline |
| E10 | EG2 raw | trained 512→512 | none | 100 | adapter-only |
| E01 (F0) | EG2 raw | none | 64 modules | 100 | adapter-free + LoRA |
| E11 (L) | EG2 raw | trained | 64 modules | 100 | adapter + LoRA |

- Primary: **E01 vs E11** (LoRA initialization matched).
- E11 vs E10: LoRA effect with adapter.
- E10 vs E00: adapter + training vs untrained baseline; confounded.

- E00 is not a trained unit.

## 3. Definitions

- EG2 layer19 h, 512 dims; M prefix K=753.
- Adapter: 512→512, Linear/GELU/Linear/LayerNorm; random init.
- Decoder LoRA: 64 mT5 q/k/v/o modules; r8 alpha16 dropout .05.
- Training: AdamW, wd .01, adapter lr 1e-3, LoRA lr 1e-4, 100 updates, batch 1, train20[step%20], clip 1.0, base decoder eval.
- M: M_POS_MEAN/M_NORM, K=753, 15 common, 120 records/cell/seed.
- Signal: donor-crop K=min(len(real),len(donor)), 20 val docs, 5 donors.
- Thresholds/seed/donor/step/LR: frozen Phase 6 values; no changes.

## 4. Initialization contract (F0-only)

F0 must not modify Phase 6 `build_arm`. New `build_arm_f0`:

```text
load_base()
torch.manual_seed(seed)
adapter = Adapter(512,512) if cell.adapter else None
torch.manual_seed(seed ^ 0x5EED10A5)   # always, adapter-independent
lora_names = attach_decoder_lora_mt5(model) if cell.lora else []
```

- `LORA_SEED_XOR = 0x5EED10A5`.
- E01/E11 call the LoRA seed reset identically.
- E10/E11 call the adapter seed identically.
- Assertions per registered seed:
  1. `lora_names` E01 == E11, length 64.
  2. `sha256(lora_A/lora_B)` E01 == E11 at init.
  3. `sha256(adapter)` E10 == E11 at init.
  4. `post_init_rng_state_sha256` E01 == E11.
  5. `lora_B` all-zero init is separately asserted, not treated as evidence of equality.
  6. E00/E01 adapter absent; E00/E10 LoRA count 0.
- `init_hashes.json` records all hashes.
- **F0 E11 ≠ Phase 6 L at init**: F0 uses a separate builder; Phase 6 checkpoints are not reused.
- `LoRA fixed` means **initialization matched only**. Dropout and optimizer RNG diverge by construction after step 0; the causal factor is `adapter-as-configured`.

## 6. Primary endpoint

### 6.1 Source and cohort

- Primary source: **final checkpoint donor-crop eval** (`unit.final.per_doc`).
- 20 val docs, 5 donors, donor-crop `K=min(len(real),len(donor))`.
- 15 common = **frozen preflight `common_ids`**.
- Presence check: all 15 `common_ids` present in `unit.final.per_doc` for every cell×seed.
- `eval_arm_d1` silently drops non-copyable docs; a missing doc means `NOT_EVALUABLE`, never a smaller cohort.
- Phase 7 = diagnostic only. Step0 = diagnostic.

### 6.2 Cell delta

For cell c, seed s, doc d:

```text
delta_c(s,d) = mean_donor( CE_wrong_donor - CE_real )
```

- copy and full separately.
- per-doc seed average: `delta_c(d) = mean_s delta_c(s,d)`.

### 6.3 Primary contrast

```text
D(d) = delta_E01(d) - delta_E11(d)     # paired, same 15 docs
mean_D = mean_d D(d)
CI_D = bootstrap_paired_v2(D, n_boot=1000, seed=20261109)
```

- Primary positive: `mean_D > 0 AND CI_D.lower > 0 AND SIGNAL(E01,copy)`.
- Copy primary; full secondary.
- **CI_D is doc-level only.** Seed-level `D_s` and split-by-seed sensitivity are descriptors, not primary.
- No per-cell significance conjunction for primary.

### 6.4 Cell signal descriptors

```text
SIGNAL(c,copy) = mean(delta_c) >= .05
                 AND CI.lower > 0
                 AND 2/3 seeds > 0
SIGNAL(c,full) = mean(delta_c) > 0
                 AND CI.lower > 0
                 AND 2/3 seeds > 0
```

- `FAIL(c,e) := NOT SIGNAL(c,e)`.
- No additional per-seed failure requirement; 2/3 seeds is already inside SIGNAL.

### 6.5 Practical null

```text
E01 ≈ E11  iff  CI_D contains 0 AND |mean_D| < .05
```

- `uncertain` if CI contains 0 but |mean_D| ≥ .05.
- No equality claim from non-significance.

### 6.6 Missing data

- Exactly 15 common docs and 3 seeds required.
- A doc/seed with missing copy or full endpoint is NA.
- No 15→14 substitution; no “2 of available”.
- If <15 or <3 seeds: `NOT_EVALUABLE`.

## 7. STOP / decision taxonomy

`PROTOCOL_VALID` requires all of:

```text
D0 pass predicate
D1 pass predicate
R mechanics pass
15 common_ids present in unit.final.per_doc for E00/E10/E01/E11 × 3 seeds
copy and full endpoints evaluable for E01/E11 × 3 seeds × 15 docs
M evaluable for all 4 cells × 3 seeds
no missing/NaN/duplicate
```

States are mutually exclusive and exhaustive, evaluated in this order:

| priority | state | condition |
|---:|---|---|
| 1 | `NOT_EVALUABLE` | not `PROTOCOL_VALID` |
| 2 | `PASS_POSITIVE` | `CI_D.lower > 0` AND `SIGNAL(E01,copy)` |
| 3 | `ROUTE_STOP` | all four `FAIL` AND (`CI_D.upper < 0` OR `E01 ≈ E11`) |
| 4 | `INDETERMINATE` | otherwise |

- `ROUTE_STOP` uses **cell-level `FAIL(c,e)`**, not “3/3 seeds”.
- `E01 ≈ E11` + both fail → `ROUTE_STOP` with reason `no_signal_no_adapter_effect`.
- `CI_D.upper < 0` + both fail → `ROUTE_STOP` with reason `adapter_associated_harm`.
- Both fail but CI is uncertain and not ≈ → `INDETERMINATE`.
- E01 positive/E11 negative but CI not >0 → `INDETERMINATE` (discordant), not PASS.
- `PASS_POSITIVE` requires E01 cell signal; a positive paired contrast with no absolute signal is not PASS.
- No post-hoc state changes.

## 9. M and signal isolation

- M_PASS is not donor-specific content-use evidence.
- M is reported separately; not a gate for F0 primary.
- M evaluability is required for `PROTOCOL_VALID`; M_PASS is not required for `ROUTE_STOP`.
- E00 is a baseline, not a trained control.
- E00 step0 = final; one signal eval.
- E10/E01/E11 step0 and final eval.

## 10. H3 — separate prereg

- `E01-LN`: raw EG2 + **frozen** LayerNorm; estimated on train20 only.
- `E01-P`: raw EG2 + **fixed orthogonal projection**; no training.
- `E01-R`: `R(x) = x + Adapter(x)`; identity is **not** assumed at init.
  - identity metric: `||R(x)-x|| / ||x||` on train20 at init; report mean/max.
  - if residual is intended to be identity-preserving, the adapter output branch must be zero-initialized; otherwise name it residual-adapter, not identity.
- H3 trigger: only after F0 `PASS_POSITIVE` or `INDETERMINATE` with adapter-associated direction; not after `ROUTE_STOP`.
- H3 requires separate prereg/approval; no H3 execution here.
