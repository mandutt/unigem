## 3. 084a — URL-only measurement baseline

### 3.1 URL soft-wrap join

source와 summary **양쪽**에 적용한다.

```text
URL token이 newline 직전에 '.', '/', '-', '_'로 끝나고,
다음 token이 source에서 URL continuation으로 attest된 경우에만 join.
```

- **source-attested**여야 한다. summary만 보고 suffix를 추측하지 않는다.
- continuation은 URL grammar에 맞는 token으로 제한한다.
- 한글·문장 시작 단어·공백 뒤 일반 단어는 join하지 않는다.
- join한 raw span, 원본 위치, repair 이유를 기록한다.
- 1,940 prediction의 `http://coronamap.\nsite`와 2,586 prediction의 `http://coronamap.site`를 **golden pair**로 둔다.
- `http://fine.fss.`처럼 문맥이 불분명한 후보는 **unresolved**로 남긴다.

### 3.2 URL canonicalization

- scheme/host만 lowercase.
- **path/query/fragment의 case, comma, escape를 보존**한다.
- trailing sentence punctuation만 별도 제거한다.
- `Case?key=A,B`와 `case?key=ab`를 같다고 보지 않는다.
- URL 외 `path`/`identifier`의 case-fold도 별도 audit 대상으로 기록한다.

### 3.3 084a audit requirement

- v1 `eval/slot_verify.py`는 **byte-identical**로 유지.
- `eval/slot_verify_v2.py` 별도 module.
- audit input은 **train/val + excluded 383**으로 제한하고 test 163을 로드하지 않는다.
- positive tests: 02742 양쪽 wrap, 2586 joined, 1,940 wrapped.
- negative tests: 문장 단어 over-join, `fine.fss.` unresolved, URL case/comma, trailing punctuation.
- 383 excluded flip은 별도 adjudication 전까지 **accept하지 않는다**.

### 3.4 084a expected result — provisional

아래는 **기존 strict failure ID에서 유도한 예상값**이며, spec-faithful audit 전에는 final이 아니다.

## 4. 084b — equivalence side channels (report-only)

084b는 084a의 gate/selection에 영향을 주지 않는다. 별도 field로 보고한다.

### 4.1 084b-1 time qualifier

- summary가 qualifier 없이 `H시[M분]`이고 source가 같은 시간을 qualifier와 함께 가지면 `qualifier_dropped`로 기록.
- summary가 qualifier를 새로 붙이면 `new`.
- source에 같은 시각의 오전/오후가 둘 다 있거나 bare time이 있으면 **unresolved**.
- 12h↔24h 변환 금지.
- **selection에는 사용하지 않는다.**

### 4.2 084b-2 numeric unit

- report-only.
- summary bare number와 source number+unit이 같은 numeric value라도 **자동 grounded로 인정하지 않는다.**
- `unit_dropped` 후보와 collision을 기록한다.
- `18%`↔`18명`, `18건`↔`18일`, `18일`↔`18명`은 금지.
- 902/1,617 numeric unit collision; 5 excluded flips.
- **selection에는 사용하지 않는다.**

### 4.3 084b-3 counter alias

- **default off**.
- `18 확진자` ↔ `18명`은 regex가 아니라 entity/scope adjudication.
- 허용하려면:
  1. closed head-noun table (`확진자`, `사망자`, `환자` → `명`)
  2. source unit이 `명`으로 명시
  3. same event/group/time scope
  4. bounded window
  5. all firings human adjudication
  6. provenance 기록
- 04709 한 건만으로 승인하지 않는다.
- **selection에는 사용하지 않는다.**
- audit의 loose alias 구현은 production rule로 사용 금지.

### 4.4 084b report fields

`qualifier_dropped`, `unit_dropped`, `alias_candidates`, `unresolved`, `per_rule_attribution`을 `selection_v2.json`과 별도 report에 기록한다.

## 6. Spec-faithful audit 구현

### 6.1 URL

- `extract_urls_v2`를 별도로 두고 raw span을 보존.
- source-attested join; summary join evidence 보존.
- path/query case·comma·escape 보존.
- `Case?key=A,B` vs `case?key=ab` negative test.
- `fine.fss.` unresolved test.
- over-join negative test.

### 6.2 Uniqueness

- **distinct typed slot** 기준.
- occurrence count와 distinct canonical count를 분리해 보고.
- `18일`과 `18명`이 함께 있는 문서는 `unit_dropped` 후보로만 기록, 자동 match 금지.
- `04951`의 `2.3%`, `2.2%`는 must-reject negative control.

### 6.3 Inputs

- audit inputs: train/val + excluded 383.
- test 163은 **로드 금지**.
- full-clean audit는 금지; 이전 audit의 all-clean 접근은 exposure history로만 기록.
- data hash와 manifest를 기록.
