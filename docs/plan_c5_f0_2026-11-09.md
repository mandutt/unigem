## 0. 목적

Phase 6의 관찰:

- P(native, no adapter)는 donor-specific signal이 있었다.
- PA(native + adapter)는 signal이 사라졌다.
- F/L(EG2 + adapter)도 signal이 없었다.
- LoRA 효과는 작았다.

그러나 다음 confound가 남아 있다.

1. F0 vs F는 adapter와 LoRA가 동시에 다르다.
2. P vs PA는 adapter 외 capacity(+526,336)와 adapter LR(10×)도 다르다.
3. EG2와 native는 memory source가 다르다.
4. “adapter bottleneck”은 구조적 진단이 아니라 관찰된 연관성이다.

이 prereg의 질문:

> **LoRA를 고정한 상태에서 adapter 유무가 EG2 donor-specific signal을 바꾸는가?**

## 1. 가설

### H1 (adapter causal)

- `E01` (EG2 raw, no adapter, decoder LoRA)는 donor-specific signal을 보인다.
- `E11` (EG2 raw + adapter, decoder LoRA)는 signal을 잃는다.
- `E01 − E11 > 0` (copy, paired 15 common docs).
- 이 경우 adapter가 원인이라는 증거가 강해진다.

### H2 (EG2 raw feature insufficient)

- `E01`도 signal이 없다.
- 이 경우 EG2 layer19 raw feature가 decoder-compatible donor signal을 제공하지 못한다.
- 단, “feature 부족”과 “alignment 부족”은 구분되지 않는다. F0 negative는 트랙 STOP의 충분조건이 아니다.

### H3 (normalization/projection)

- adapter의 LayerNorm 또는 fixed projection이 원인일 수 있다.
- `E01-LN`: raw EG2 + fixed LayerNorm (no learned adapter).
- `E01-P`: raw EG2 + fixed orthogonal projection (no training).
- `E01-R`: residual adapter `x + Adapter(x)` (identity-preserving).
- 이 arms는 H3이며 primary 2×2와 분리한다.

## 2. 2×2 설계

| cell | memory | adapter | decoder LoRA | updates | 역할 |
|---|---|---|---|---|---|
| E00 | EG2 raw 753×512 | none | none | 0 | eval-only baseline |
| E10 | EG2 raw 753×512 | trained 512→512 | none | 100 | adapter-only |
| E01 (F0) | EG2 raw 753×512 | none | 64 modules | 100 | **primary adapter-free** |
| E11 (L) | EG2 raw 753×512 | trained 512→512 | 64 modules | 100 | adapter+LoRA |

- **Primary contrast: E01 vs E11** (LoRA fixed; adapter differs).
- Secondary: E10 vs E00 (adapter without LoRA; E00 is 0-update baseline, not a trained control).
- Do not interpret E01 vs E10 as clean; LoRA and training path differ.
- E00 has no trainable parameters; it is an evaluation-only baseline, not a 4th trained unit.

### 2.1 Arm code

- `E01`: raw EG2 h (512) fed directly to mT5 decoder; attach decoder LoRA; no Adapter.
- `E11`: Adapter(h); attach decoder LoRA.
- `E10`: Adapter(h); no LoRA.
- `E00`: raw h; no adapter; decoder frozen; 0 updates.
- All use `summarize: ` prefix, mT5-small, source max 512? For EG2 memory, source h token length; target max 256.
- M K = 753 for all EG2 arms.
- Adapter geometry same as Phase 6: 512→512, GELU, LayerNorm.
- Decoder LoRA same 64 modules, r8 alpha16 dropout .05.

## 8. Stage D decision (prospective)

Stage D is not a gate. Proceed to Stage R only if:

```text
E01 copy mean delta > 0
AND E01 − E11 paired copy mean > 0
AND both E01/E11 endpoints finite on 15 common docs
```

- If true → Stage R 3 seeds.
- If false → **STOP F0**; no 3-seed, no threshold change.
- Stage D is 1 seed only; no statistical claim.
- If E01 negative and E11 negative → EG2 raw feature/alignment insufficient; stop EG2 resident track.
- If E01 positive and E11 positive → adapter not necessary under this regime; investigate replication/anomaly, not H3.
- If E01≈E11 → adapter effect not supported; stop adapter hypothesis.
