## 4. Initialization contract (F0-only)

F0 must not modify Phase 6 `build_arm`. New `build_arm_f0`:

```text
load_base()
torch.manual_seed(seed)
adapter = Adapter(512,512) if cell.adapter else None
torch.manual_seed(seed ^ 0x5EED10A5)   # always, adapter-independent
lora_names = attach_decoder_lora_mt5(model) if cell.lora else []
# per-step deterministic RNG, all cells:
# step_seed = seed ^ (0x9E3779B9 * (step+1)) & 0xffffffff
# torch.manual_seed(step_seed) before each forward
```

- `LORA_SEED_XOR = 0x5EED10A5`.
- `STEP_SEED_MUL = 0x9E3779B9`.
- E01/E11 call the LoRA seed reset identically.
- E10/E11 call the adapter seed identically.
- Per-step reseed is structural: every cell uses the same `step_seed(seed, step)` before forward, so dropout RNG is identical, not merely assumed.
- Assertions per registered seed:
  1. `lora_names` E01 == E11, length 64.
  2. `sha256(lora_A/lora_B)` E01 == E11 at init.
  3. `sha256(adapter)` E10 == E11 at init.
  4. `post_init_rng_state_sha256` E01 == E11.
  5. `post_step0_rng_state_sha256` E01 == E11.
  6. `lora_B` all-zero init is separately asserted, not treated as evidence of equality.
  7. E00/E01 adapter absent; E00/E10 LoRA count 0.
  8. `base_state_sha256`, `cache_sha256`, `labels_sha256` recorded and equal across cells.
  9. `post_step0_weight_change`: at least one LoRA/adapter parameter changes; exact tensor hash differs from init.
- **step_seed golden table** (unit test vectors):
  - `step_seed(20261108,0)=0x9f02514d`, `(20261108,1)=0x3d5bdb86`, `(20261108,2)=0xdb9345df`; seeds 20261109/10/20261111 likewise: `0x9f02514c/4f/4e`, `0x3d5bdb87/84/85`, `0xdb9345de/dd/dc`.
  - Formula is `(seed ^ ((0x9E3779B9 * (step+1)) & 0xffffffff)) & 0xffffffff`.
  - Parentheses fixed; no operator-precedence ambiguity.
- Canonical tensor serialization: `name_len|dtype|ndim|shape|nbytes|LE bytes`, SHA-256.
- `init_hashes.json` records all hashes; canonical digest = sorted key + `\0` + UTF-8 value, SHA-256; capture point = immediately after builder returns, before D0 forward.
- **Phase 6 I/O assert**: F0 must not open any Phase 6 checkpoint; `open`/`torch.load` path audit records zero Phase 6 paths. This replaces the untestable “F0 E11 ≠ Phase 6 L”.
- `LoRA fixed` means **initialization matched**; it does not mean trained weights remain equal.
- RNG equality is **structural** via per-step reseed, not assumed.
- The causal factor is `adapter-as-configured` (adapter params + adapter LR + adapter-conditioned forward graph).

### 6.2 Cell delta

For cell c, seed s, doc d:

```text
delta_c(s,d) = mean_donor( CE_wrong_donor - CE_real )
```

- copy and full separately.
- per-doc seed average: `delta_c(d) = mean_s delta_c(s,d)`.

### 6.3 Primary contrast

```text
D(d) = delta_E01(d) - delta_E11(d)     # paired, same 15 docs
mean_D = mean_d D(d)
CI_D = bootstrap_paired_v2(D, n_boot=10000, seed=20261109)  # explicit override of frozen N_BOOT=1000
```

- Primary positive: `mean_D > 0 AND CI_D.lower > +.05 AND SIGNAL(E01,copy) AND 2/3 seeds D_s>0`.
- `D_s` = paired E01−E11 contrast per seed; seed-sign gate tests replication, not a second primary.
- Copy primary; full secondary.
- **CI_D is doc-level only.** Seed-level `D_s` is a gate/descriptor, not a doc-level interval.
- `PASS_POSITIVE` requires the paired contrast, E01 absolute copy signal, and seed replication; this is not a per-cell significance conjunction.

### 6.4 Cell signal descriptors

```text
SIGNAL(c,copy) = mean(delta_c) >= .05
                 AND CI.lower > 0
                 AND 2/3 seeds > 0
SIGNAL(c,full) = mean(delta_c) > 0
                 AND CI.lower > 0
                 AND 2/3 seeds > 0
```

- `FAIL(c,e) := NOT SIGNAL(c,e)`.
- No additional per-seed failure requirement; 2/3 seeds is already inside SIGNAL.

### 6.5 Practical equivalence

```text
EQUIVALENT  iff  95% CI_D is entirely within [-.05, +.05]
```

- `EQUIVALENT` is a practical-equivalence label; it is not a population equality claim.
- No population equality inference is made from this 15-doc cohort.
- With n=15 paired half-width .0376, EQUIVALENT mean range is ≈±.0124; ALL_FAIL→ROUTE_STOP is the more likely branch given Phase 6 F/L −.111/−.1135. Plain INDETERMINATE is not the expected dominant null.

### 6.6 Missing data

- Exactly 15 common docs and 3 seeds required.
- A doc/seed with missing copy or full endpoint is NA.
- No 15→14 substitution; no “2 of available”.
- If <15 or <3 seeds: `NOT_EVALUABLE`.

## 7. STOP / decision taxonomy

`PROTOCOL_VALID` requires all of:

```text
D0 pass predicate
D1 pass predicate
R mechanics pass
15 common_ids present in unit.final.per_doc for E00/E10/E01/E11 × 3 seeds
copy and full endpoints evaluable for E01/E11 × 3 seeds × 15 docs
each doc has exactly 5 donors; donor sets identical for E00/E10/E01/E11
M evaluable for all 4 cells × 3 seeds
no missing/NaN/duplicate
```

Definitions:

```text
ALL_FAIL = FAIL(E01,copy) AND FAIL(E01,full)
           AND FAIL(E11,copy) AND FAIL(E11,full)
EQUIVALENT = CI_D.lower >= -.05 AND CI_D.upper <= +.05
harm      = CI_D.lower > 0 AND NOT EQUIVALENT
benefit   = CI_D.upper < 0 AND NOT EQUIVALENT
```

Reason precedence when multiple labels apply:

```text
EQUIVALENT > harm > benefit
```

States are mutually exclusive and exhaustive, evaluated in this order:

| priority | state | condition |
|---:|---|---|
| 1 | `NOT_EVALUABLE` | not `PROTOCOL_VALID` |
| 2 | `PASS_POSITIVE` | `mean_D>0` AND `CI_D.lower > +.05` AND `SIGNAL(E01,copy)` AND 2/3 seeds `D_s>0` |
| 3 | `ROUTE_STOP` | `ALL_FAIL` (reason enum: `no_signal_equivalent` > `adapter_harm` > `adapter_benefit` > `no_signal_uncertain`) |
| 4 | `INDETERMINATE` | not `ALL_FAIL`, and not `PASS_POSITIVE` |

- `ALL_FAIL` is exactly **E01/E11 × copy/full**; E00/E10 are excluded.
- `ROUTE_STOP` uses **cell-level `FAIL(c,e)`**, not “3/3 seeds”.
- `ALL_FAIL` + EQUIVALENT → `ROUTE_STOP` reason `no_signal_equivalent`.
- `ALL_FAIL` + harm → `ROUTE_STOP` reason `adapter_harm`.
- `ALL_FAIL` + benefit → `ROUTE_STOP` reason `adapter_benefit`.
- `ALL_FAIL` + none of EQUIVALENT/harm/benefit → `ROUTE_STOP` reason `no_signal_uncertain`.
- `INDETERMINATE` = some cell signal exists but no positive/stop classification; no automatic H3; new prereg required.
- E01 positive/E11 negative but CI not >.05 → `INDETERMINATE` (discordant), not PASS.
- `PASS_POSITIVE` requires E01 cell signal and lower bound >.05; a small positive paired contrast inside the equivalence band is not PASS.
- No post-hoc state changes.
