# G-DATA 제안서 — 외부 LLM API 사용 승인 요청

- 작성: 2026-11-02
- 상태: **미승인 · 호출 없음**
- 대상: Addendum B §B-13 `G-DATA_proposal.md`

## 1. 목적

| 용도 | 필요한 이유 | 대체 가능성 |
|---|---|---|
| C3 어댑터 학습 데이터(EG2 hidden → T5Gemma 2) | H4′ PASS로 위치 정렬은 성립하나, 어댑터 학습쌍이 필요 | 공개 instruction 데이터로 일부 대체 가능(품질 낮음) |
| F4 오류-교정 쌍 증강 | AI Hub 205,550레코드로 부족한 유형(문맥 의존) 보강 | 규칙 합성으로 대체 가능(현 P1) |

## 2. 데이터 등급 (제안)

- **P0(공개·합성)만** 외부 API로 전송한다.
- P1(개인 음성·메모·일기)은 **전송 금지**. 프롬프트에 포함하지 않는다.
- 전송 전 자동 필터: 이메일·전화번호·주민번호·주소 패턴 차단, 사용자 파일 경로 제거.

## 3. 규모·비용 (상한)

| 항목 | 값 |
|---|---|
| 요청 문장 | 최대 30,000건 (C3 20,000 + F4 10,000) |
| 평균 입출력 | 입력 300토큰 / 출력 300토큰 |
| 총 토큰 | 약 18M |
| 예상 비용 | 모델 단가에 따라 $20~$120 (상한 $150) |
| 호출 시점 | 승인 후, 배치 1회 |

## 4. 안전 규칙

1. 승인 전 **어떤 외부 LLM API도 호출하지 않는다**(현재 0회).
2. API 키는 환경변수만 사용, 파일·보고서·로그에 기록하지 않는다.
3. 요청/응답 원문은 `data/external/`에 저장하되 PII 필터 통과분만.
4. 결과물은 학습 데이터로만 사용하고, 운영 추론 경로에는 외부 API를 두지 않는다.
5. 실패·한도 초과 시 재시도 3회 후 중단하고 보고한다.

## 5. 승인 요청 항목

| # | 항목 | 기본 제안 |
|---|---|---|
| 1 | 외부 API 사용 승인 | **필요** |
| 2 | 제공자·모델 | 미정(승인 시 지정) |
| 3 | 데이터 등급 | P0만 |
| 4 | 최대 비용 | $150 |
| 5 | 보관 기간 | 프로젝트 종료 시 삭제 |

## 6. 현재 상태

- G-DATA 게이트: **미승인**
- 외부 호출 이력: **없음**
- C3/F4는 공개·합성 데이터만으로 진행 중이며, 승인 없이도 현재 단계는 막히지 않는다.
