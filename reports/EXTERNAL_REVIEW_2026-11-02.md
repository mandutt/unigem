## 0. 한 줄 요약

EmbeddingGemma 2(EG2)를 상주 인코더로 재사용해 F1(언어판정)·F2(STT)·F3(비전 태깅)·F4(맞춤법)·F5(요약)·F6(STT 후처리)을 구현할 수 있는지 실측하는 프로젝트다. Phase A(ONNX 다중 출력화)와 VPS 검증은 통과했고, Phase B1.5에서 **텍스트 hidden의 표면 보존(G-B1.5-a)과 문맥 가치(G-B1.5-b)가 모두 FAIL**했다. Q8 견고성만 PASS다.

## 2. Phase A — ONNX 다중 출력화

| 항목 | 결과 |
|---|---|
| 텍스트 그래프 | 9출력(`tok_h_l00/04/08/12/16/20`, `last`, `pooled`, `sentence_embedding`), FP32 1.089GB |
| 텍스트 parity | 층별 cosine 최소 **0.999999999998**, NaN 0 → PASS |
| 오디오 그래프 | q8 12층 수술(`type_as_{8+9i}` + `linear_133`), FP32 연구용 t500/t1600/t1600_l12/t3000 |

| Q8 | MatMulNBits 8bit/block128/acc4, 684MB (−37%), 층별 cos 최소 0.9977 |
| LID 회귀 | G-A3L 43/44(97.7%) FAIL → G-A3L-R 220클립 **216/220(98.18%) FAIL** (기준 99%) |
| 지연 | 텍스트 Q8 512tok p50 **540ms**(threads 6) |

**미해결:** G-A3L-R FAIL(98.18% < 99%, 확신 오판 21→23). Q8 교체 보류 상태.

## 7. 검토 요청 사항 (핵심)

1. **G-B1.5-a 기준 98%가 과도한가?** 코퍼스 v2는 식별자·오타·숫자를 포함하고 어휘가 14,789로 커졌다. B1(9,166 클래스)에서는 l00 99.57%였다. 기준을 유지해야 하는가, 아니면 "식별자 span exact" 중심으로 재정의해야 하는가?
2. **G-B1.5-b 판정**: T1만 +10.6%p, T2 +1.87%p(CI 하한 >0), T3는 천장. "2/3 과제" 규칙을 FAIL로 확정하는 것이 타당한가? T3 설계 결함(천장)을 감안해 재설계 후 재판정해야 하는가?
3. **텍스트 hidden 폐기 규칙**: 게이트 FAIL 시 "EG2 텍스트 hidden 폐기"가 사전 등록되어 있다. 그러나 T1 결과는 F4에 부분 근거를 준다. 폐기 대신 "F4 한정 채택 + F5 보류"가 정당한가?
4. **B1.5-4 복사 디코더**: 상위 게이트 FAIL 상태에서 20k 샘플 디코더 학습(CPU 수 시간)을 수행할 가치가 있는가? 아니면 F5를 보류하고 F4/F2/F3에 집중해야 하는가?
5. **G-A3L-R FAIL(98.18%)**: 220클립에서 99% 기준과 확신 오판 +2건. 운영 교체를 보류하는 것이 맞는가? 아니면 44클립 Q8 44/44 결과를 근거로 예외를 인정할 수 있는가?
6. **C3 설계**: H4 기각(id 불일치 6,186) 후 EG2 hidden → T5Gemma 2 디코더 경로는 토큰 id 정렬 없이 가능한가? 아니면 디코더를 포기하고 F4를 규칙+경량 헤드로 한정해야 하는가?
7. **접두사 미측정**: EG2 모델 카드의 문서/질의 접두사가 F4·F5에 미치는 영향을 무시해도 되는가?
8. **우선순위**: 남은 Phase C 항목(C1 비전 export, C2 STT CER, C3 디코더, C4 맞춤법, C5 요약) 중 다음 착수 순서를 어떻게 정해야 하는가?
