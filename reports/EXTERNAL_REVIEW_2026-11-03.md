### 1.3 EG2 구조 (실측 확인)

| 구성 | 값 |
|---|---|
| 텍스트 백본 | hidden 512, 24층, 양방향 |

| 출력 | `sentence_embedding` 768, 토큰 hidden 512 |
| 오디오 운영 그래프 | `eg2_audio_q8_layers.onnx` (12층 + pooled), Q8 |

### 1.4 Notesoop 구조 (F2 기준선)

```
16kHz audio
  → EG2 오디오 타워 (동결, 12층)
  → audio_features [T,512]
  → LM 24층 → final norm
  → embedding_projection[:256] → L2
  → Conformer reader (CTC, 25k 어휘)
  → greedy decode (KenLM 선택)
```

- 청크 16초 / 오버랩 1초, greedy(기본 KenLM 미사용).
- **EG2는 인코더 전용 모델**이므로 생성 능력이 없다. STT를 하려면 별도 reader/디코더가 필수다.
- Notesoop-STT-Ko-v1은 이 구조의 한국어 인스턴스이며, 우리는 **reader 가중치를 우리 데이터로 다시 학습하는 것**을 D안으로 검토 중이다.

- **G-C2a:** Q8 특징 코사인 평균 **0.999642**, CER 상대 변화 **−0.12%** (기준 ≤ +10%) → **PASS(측정)**. 단, 게이트 승인은 CP-C1에서.

### 4.2 D안의 구조 선택지 (Exa 조사 결과)

D는 하나가 아니라 **같은 "동결 인코더 + 경량 reader" 계열의 여러 변형**이다. 최근 공개 사례는 다음과 같다.

| 변형 | 구조 | 공개 사례·수치 | 우리 적합성 |
|---|---|---|---|
| **D-α. 단일 층 + CTC** (현재) | 마지막 hidden → CTC reader | Embed2ASR: 9.66M GRU-CTC, 4,996 unit, **Whisper large-v3보다 뒤**, 동음이의어·frozen ceiling | 기준선(18.96%) |
| **D-β. 다층 혼합 + CTC** | 중간층 4~5개를 학습 가중치로 혼합 → CTC | arXiv 2610.28673(아랍어): 22.6M reader, 2.07B Cohere와 **CER 유의차 없음(5/6)**, CPU 3.4배 빠름 | **높음.** C-7 탭 확장으로 구현 가능 |
| **D-γ. LoRA + hybrid CTC/attention** | encoder 중간층 LoRA 3.1M + 41.5M hybrid reader + subword LM | 같은 논문 adapted: WER **19.20% vs 19.27%** (0.6B FT와 동등), 6조건 CER 우위 | 중간. **encoder 수정·Q8 재export** 필요 |
| **D-δ. 증류(distillation)** | 교사(komix/whisper) pseudo-label → 작은 CTC student | Distil-Whisper: 21,170h pseudo-label, 2-layer decoder, **원 모델 WER 1% 이내** | **높음.** reader만 학습, 교사는 이미 로컬 |
| **D-ε. projector + frozen LLM** | encoder → projector → 동결 LLM | SLAM-ASR: 선형 projector만; AZeroS: 23.8M projector, 25k시간; Diffusion ASR: 42M, 6.6% LibriSpeech | **낮음.** LLM 상주/메모리·지연 |
| **D-ζ. 검색(최근접)** | audio embedding → 텍스트 embedding 최근접 | Apple acoustic neighbor: 500k 어휘에서 FST와 동일 정확도 | **낮음.** 고립 단어만, open-ended 불가 |

**권고:** D-β(다층 혼합 CTC) + D-δ(komix 증류)를 **1차 조합**으로 하고, 15% 미달 시 D-γ(LoRA)를 2차로 둔다.

- 1차 조합은 **encoder를 전혀 건드리지 않으므로** ONNX Q8 단일 상주 구조가 유지된다.
- D-γ는 encoder 가중치를 수정(merge)하고 재export해야 하므로 "원본 가중치 불변" 원칙과 충돌한다. 사용자 승인이 필요하다.
- D-ε는 15.6GB RAM에서 LLM 상주가 어렵고, 온디맨드여도 콜드 로드·생성 지연이 크다.
- D-ζ는 "자유 문장 전사"가 아니라 **어휘 집합 내 분류**라 F2 목적에 부합하지 않는다.

## 5. 검토 요청 질문

각 질문에 **판단 + 근거 + 반대 가능성**을 주시면 된다. 선택지가 있으면 선택해 주면 된다.

### Q1. CP-C1 — D안이 합리적인가?

- D는 "단일 EG2 상주"를 유지하지만, 13.5%p 격차를 reader 학습만으로 메울 근거가 아직 없다.
- A/B는 G-C2를 여유 있게 통과하지만 별도 런타임을 추가한다.
- 질문: **D를 1차로 진행하는 것이 합리적인가, 아니면 B(whisper)를 채택하고 F2를 먼저 닫는 것이 프로젝트 전체 정보 가치가 높은가?**
- 판단 기준: ① 15.6GB RAM에서 동시 상주 가능성 ② CPU RTF ③ 구현·유지 비용 ④ "단일 상주" 목표의 중요도.

### Q2. D-β + D-δ 조합이 최선인가?

- D-β(다층 혼합 CTC)는 아랍어 사례에서 2B 모델과 CER 동등(5/6)을 보였다.
- D-δ(증류)는 Distil-Whisper에서 원 모델 1% 이내를 보였다.
- 질문: **둘을 결합하는 것이 맞는가?** 아니면 D-β만 먼저 하고, 증류는 15% 미달 시에만 하는 것이 맞는가?
- 반대 가능성: 다층 혼합은 구현 복잡도가 있고, 단일 층 대비 이득이 한국어에서 재현되지 않을 수 있다. 증류는 교사(komix)의 오류를 student가 학습할 위험이 있다.

### Q3. D-γ(LoRA)를 허용해야 하는가?

- D-γ는 encoder 중간층에 LoRA 3.1M를 넣고 hybrid reader 41.5M를 쓰는 방식으로, 아랍어 adapted 사례에서 WER 19.20 vs 19.27을 달성했다.
- 그러나 encoder 가중치를 수정·merge하고 Q8 ONNX로 재export해야 하며, "원본 가중치 불변" 원칙과 충돌한다.
- 질문: **D-β/δ가 15%에 미달할 경우 D-γ를 허용할 것인가?** 허용한다면 어떤 조건(예: LoRA는 사본에만, 원본 불변, Q8 parity 재검증)을 붙여야 하는가?

### Q4. G-C2 15% 임계값을 D에도 그대로 적용하는 것이 타당한가?

- 15%는 Notesoop 기준으로 사전등록된 값이다. D는 새로운 학습이므로 "같은 게이트"를 적용하는 것이 공정한지 논쟁 여지가 있다.
- 질문: **D에도 15%를 그대로 적용해야 하는가?** 아니면 D는 "Notesoop 대비 개선"을 1차 목표로 하고, 15%는 별도 사전등록으로 두어야 하는가?
- 주의: 결과를 본 뒤 임계값을 완화하는 것은 금지. 검토 시점에서 **사전에** 정해야 한다.

### Q5. 학습 데이터 규모와 구성
