# C5 B2 gold 300 — data scaling result (2026-11-07)

## 1. 요약

B2 gold100의 99문서 overfit을 완화하기 위해 train 300 / val 100으로 확장했다.

- trainer: adapter + decoder LoRA
- init: `b1d_teacher100/adapter_final.pt`
- target: gold summary
- train **300**, val **100**, 2 epoch
- test 163 미사용

**data scaling 효과는 확인됐지만, val100 기준으로는 B2 full과 비슷한 수준이며 grounding 18%가 병목이다.**

## 2. 학습

| 항목 | 값 |
|---|---:|
| train CE | 2.9054 → **1.9428** |
| val CE | 2.9375 → **2.8314** |
| elapsed | **2,576.8s (42.9분)** |
| steps | 600 |
| checkpoint | every 50 |

- B2 gold100은 val CE가 2.9375 → 2.9969로 **악화**됐다.
- B2 gold300은 val CE가 **−0.1061 개선**됐다.
- 즉 100문서 overfit은 data scaling으로 **부분 완화**됐다.

## 6. 판정

**DATA_SCALING_PARTIAL_GROUNDING_UNCHANGED**

- val CE와 teacher-forced fidelity는 개선됐다.
- val100 free-running F1 **0.3341**, grounded **18%**, EOS **67%**.
- **F1/grounded는 B2 full(1,293)과 거의 같고**, EOS는 67% vs 60.25%로 약간 높다.
- **300문서로 1,293문서와 비슷한 free-running 품질에 도달**했지만,
  grounding 18%는 여전히 제품 기준에 미달한다.
- val20 F1 0.3664는 **낙관적 추정**이었다.
- 제품 후보 없음; **pilot300 fallback 유지**; **test 163 sealed**.
