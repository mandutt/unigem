# C5 B2 layer12 300 — decoder LoRA r16 결과 (2026-11-08)

## 1. 요약

layer12 512 + MLP1536, 300문서, gold target에서 decoder LoRA rank를
r8 → r16으로 확대했다.

**r16은 val CE, teacher-forced fidelity, free-running F1 모두 r8보다 나쁘다.**
grounded만 높아졌지만 EOS/rep4가 악화됐다.

## 2. 학습

| 항목 | r8 | **r16** |
|---|---:|---:|
| decoder LoRA params | 737,280 | **1,474,560** |
| train CE | 3.6872 → 1.4014 | 3.6872 → **1.3924** |
| val CE | 3.6873 → **2.2983** | 3.6873 → **2.3536** |
| elapsed | 2,595.3s | **2,563.6s** |

- train CE는 r16이 약간 낮지만 **val CE는 더 나쁘다** → overfit.

## 3. Teacher-forced fidelity (target=teacher)

| system | CE | token acc |
|---|---:|---:|
| B2 layer12 r8 | **2.1190** | **56.11%** |
| B2 layer12 r16 | 2.1723 | 54.88% |

- rank 확대가 teacher-forced fidelity도 악화시켰다.

## 4. Free-running val20

| metric | r8 same20 | **r16** |
|---|---:|---:|
| char F1 | **0.3623** | 0.2765 |
| teacher F1 | **0.3483** | 0.2610 |
| grounded | 10% | **35%** |
| EOS | **65%** | 45% |
| rep4 | **0.589** | 0.696 |
| gen_len | 290.1 | 346.3 |

- r16은 grounded가 높지만 **F1/EOS/rep4가 모두 악화**됐다.
- “grounded를 위해 품질을 버리는” 방향이라 제품 후보가 아니다.

## 5. 판정

**DECODER_R16_NO_GAIN**

- decoder rank는 현재 병목이 아니다.
- r16은 overfit을 키우고 free-running을 악화시켰다.
- **r8이 계속 우세**.
- 제품 후보 없음; pilot300 fallback; test 163 sealed.
