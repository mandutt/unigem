## 4. 해석

### B2가 확인한 것

1. **decoder LoRA는 EOS와 반복을 개선한다.**
   - EOS 0.10 → 0.40
   - repeated-4gram 0.774 → 0.649
2. **decoder가 adapter hidden을 더 사용하게 되는 방향은 맞다.**
3. **그러나 20문서로는 일반화되지 않는다.**
   - val CE 악화
   - grounded 0

### 아직 해결되지 않은 것

- **grounding** — new-slot 0.92, grounded 0
- **반복** — 0.649도 제품 기준이 아님
- **full-scale 일반화** — 20문서 pilot은 근거 부족
- **usage enforcement** — decoder가 H_s를 얼마나 실제로 쓰는지 모름

## 5. 다음 선택지

### B2 full — 1,293 × 2 epoch

- 가장 직접적인 확장
- 20문서 overfit이 full에서 해소되는지 확인
- 예상: 수 시간 (CPU)
- grounded가 개선될지는 미지수

### B2 + usage-contrast

LLINK식:

```text
L = L_CE(H_s) + λ * max(0, L_zero - L_CE(H_s) + margin)
```

- H_s를 zero/원래 embedding으로 되돌렸을 때 loss가 더 좋아지면 패널티
- decoder가 H_s를 실제로 사용하도록 강제
- B2 full보다 먼저 20문서 pilot으로 효과 확인 가능

### B1d-CE full

- decoder LoRA 없이 1,293 전체 CE
- B2보다 단순하지만 반복·환각이 남을 가능성

## 6. 권고

**B2 full보다 먼저 B2 + usage-contrast 20문서 pilot**을 권장한다.

이유:

- B2 pilot에서 val CE가 악화된 것은 overfit이지만,
- grounded 0은 “H_s를 사용하지 않거나, 사용해도 grounding하지 않는다”는 신호다.
- usage-contrast는 이 문제를 직접 겨냥한다.
- 20문서 pilot은 2~4분이면 된다.

그 다음:

1. usage-contrast가 EOS/반복/grounded를 개선하면 → B2 full
2. 효과가 없으면 → B2 full 또는 B1d-CE full
3. test 163은 계속 sealed
