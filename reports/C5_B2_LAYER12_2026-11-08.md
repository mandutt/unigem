# C5 B2 layer12 512 — final 768 대비 (2026-11-08)

## 1. 요약

EG2 final 768 대신 **layer12 512**를 입력 feature로 사용하고,
layer12 hidden-pretrained adapter(MLP1536)를 초기값으로 B2 300을 학습했다.

- train 300 / val 100
- gold target
- adapter + decoder LoRA
- test 163 미사용

**teacher-forced fidelity는 큰 폭으로 개선**됐다.

## 2. 설정

| 항목 | 값 |
|---|---|
| input | EG2 `hidden_states[12]` 512 |
| adapter | 512 → 1536 → 640, LayerNorm, scale |
| init | layer12 hidden-pretrained MLP1536 |
| train / val | 300 / 100 |
| target | gold summary |
| decoder | T5Gemma2 frozen + q/k/v/o LoRA r8 α16 |
| epochs | 2 |
| lr | 3e-4 |
| elapsed | **2,595.3s (43.3분)** |

## 3. 학습 CE

| 항목 | before | after |
|---|---:|---:|
| train CE | 3.6872 | **1.4014** |
| val CE | 3.6873 | **2.2983** |

- B2 gold300 final 768: val CE **2.8314**
- B2 full 1,293: val CE **2.6341**
- **layer12 300이 B2 full보다 낮은 val CE**를 기록했다.

## 4. Teacher-forced fidelity (target=teacher)

| system | data | CE | token acc |
|---|---:|---:|---:|
| adapter-only teacher100 | 99 | 2.7705 | 43.58% |
| B2 gold300 final 768 | 300 | 2.7204 | 44.92% |
| B2 full 1,293 | 1,293 | 2.6341 | — |
| **B2 layer12 300** | **300** | **2.1190** | **56.11%** |

- final 768 대비 **CE −0.6014**, token **+11.19%p**
- 가장 큰 teacher-forced 개선이다.

## 5. Free-running val100

| metric | B2 gold300 (final 768) | **B2 layer12 300** | Δ |
|---|---:|---:|---:|
| char F1 | 0.3341 | **0.3464** | **+0.0123** |
| teacher char F1 | 0.3287 | **0.3392** | +0.0105 |
| grounded | 18% | **21%** | **+3%p** |
| EOS | 67% | **60%** | **−7%p** |
| rep4 | 0.592 | 0.588 | −0.004 |
| gen_len | 276.1 | 309.6 | +33.5 |

- F1/grounded는 개선됐지만 **teacher-forced 개선폭에 비해 작다.**
- EOS는 67% → 60%로 악화됐다.
- 즉 layer12 feature는 **content/fidelity**를 개선하지만,
  **free-running/exposure bias/grounding**은 별도 문제로 남는다.

## 6. 판정

**LAYER12_FEATURE_GAIN_PARTIAL**

- teacher-forced: **큰 개선** (CE 2.7204 → 2.1190, token 44.92% → 56.11%)
- val CE: **2.8314 → 2.2983**
- free-running: **F1 +0.0123, grounded +3%p, EOS −7%p**
- **feature layer 선택은 유효**하지만, free-running 격차를 모두 해소하지는 못함
- B2 full 1,293(F1 .3349, grounded 18.01%)보다 F1/grounded는 약간 높지만,
  **A1 native(.6576/100%)에는 크게 미달**
- 제품 후보 없음; **pilot300 fallback 유지**; **test 163 sealed**
