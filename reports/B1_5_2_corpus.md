## 2. 식별자 출처

| 종류 | 수량 | 출처 |
|---|---|---|
| 파일 경로 | 250 | 설치된 공개 패키지(Apache/BSD)의 상대 경로 |
| 버전 | 150 | 패키지 METADATA |
| 설정 키 | 100 | HF 캐시의 config.json 키 |
| URL | 50 | 패키지 메타데이터 Project-URL |
| 커밋 SHA | 150 | 로컬 git 이력(40자) — 공개 저장소 아님을 명시 |
| 오류 코드 | 100 | 규칙 생성(E####) |

- SHA는 **공개 저장소가 아닌 프로젝트 git 이력**에서 추출했다. Addendum의 "공개 저장소" 조건에는 미달이며, 후속으로 transformers/llama.cpp 등에서 보강해야 한다.
- 라이선스 표기: `Apache-2.0/BSD`(패키지), `CC BY 4.0`(FLEURS), `synthetic-rule`(숫자·오류코드).

## 4. 미달 항목과 원인

1. **ja/zh 자연 문장 부족**: FLEURS test tsv에서 유효 전사가 147/112건뿐. train/validation split을 추가로 받아야 300을 채울 수 있다(현재 HF 경로 404, parquet 재확인 필요).
2. **식별자 800 미달**: 고유 span 582. 공개 저장소(GitHub API)에서 SHA·경로를 추가 추출하면 충족 가능하나, API rate limit 대비 비용이 있다.
3. **길이 257–512 구간 93건**: 문장 연결 후 512토큰 절단으로 100을 채우지 못했다.
