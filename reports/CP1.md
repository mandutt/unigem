## 3. 판정 해석

- **텍스트 경로는 Phase A를 통과했다.** FP32는 PyTorch와 사실상 동일(cos≈1), Q8은 G-A4 기준을 여유 있게 충족.
- **G-A3L FAIL은 실질 회귀가 아니라 게이트 정의 문제다.** 유일한 불일치는 id↔ms 초근접 경합(margin 0.0094 vs 0.0068)이며,
  기존 판정기가 ms로 틀린 클립을 신규 FP32가 id로 맞혔다. Q8에서는 다시 ms로 돌아와 44/44 일치.
  즉 두 그래프의 차이는 양자화 잡음 수준이고, “확신 오판 증가 0”은 충족한다.
- **오디오 다층 hidden은 확보됐다.** q8 파생(12층)과 FP32 연구용(t500·t1600) 모두 있다. C2(STT reader)는 두 경로를 모두 쓸 수 있고,
  G-A3S는 t1600 그래프로 원 추출기와 직접 비교하면 된다.

| 안 | 내용 | 영향 |

### D2. 오디오 다층 경로 (해결됨 — 보고)

**q8 운영 경로: 옵션 C(기존 q8 그래프에 층 출력 추가) 채택.** 원본 불변, 파생 사본만 수정.
**FP32 연구 경로: export 성공** (dynamo + 정적 shape + `optimize=False`). 원인 4중 규명은 `A2_export_audio_research.md`.

| 경로 | 산출물 | 검증 |
|---|---|---|
| q8 운영 | `eg2_audio_q8_layers.onnx` (12층 + out_proj) | cos 0.99945~0.999998 |
| FP32 연구 (5초) | `eg2_audio_research_fp32_t500.onnx` | cos 1.0, NaN 0 |
| FP32 연구 (16초) | `eg2_audio_research_fp32_t1600.onnx` | 스모크 통과 (패리티는 t500에서 확인) |

제약: FP32 그래프는 **정적 shape**이다. 입력 길이별 그래프가 필요하다.

### D5. 오디오 연구용 그래프의 길이 세트·패딩 정책

| 안 | 내용 | 영향 |
|---|---|---|
| **A (권장)** | 500(5s) + 1600(16s, Notesoop 청크) + 3000(30s) 3종을 미리 export하고, 런타임은 가장 가까운 긴 그래프에 zero-pad + mask | 실시간 스트림·배치 모두 커버. 그래프당 디스크 1.22GB(가중치 3벌) → 총 3.7GB |
| B | t1600만 유지, 16초 초과는 16초 윈도우로 분할 | 디스크 최소. 30초 문맥이 필요한 실험(C2-A1 long-form)에는 부족 |
| C | 필요할 때마다 즉석 export | 디스크 최소. export 2~3분/회, 재현성 관리 부담 |

- 권장 A의 전제: 디스크 여유. 로컬 여유는 확인 필요(현재 그래프 2개 = 2.4GB 사용 중).
- 어느 안이든 **성능 판정은 로컬**이며, 정적 그래프 특성상 배치 처리는 루프로 한다.

### D3. 상주 EG2 구성 확정 (CP1 본래 안건)

현재 측정으로 확정 가능한 범위:
- 타워: **텍스트 + 오디오** (비전은 C1 시점 추가)
- 출력 층: 텍스트 `{0,4,8,12,16,20,last}` 전부 노출(연구용), 운영은 B2 결과 후 축소
- dtype: **Q8 (q8-al4)** — G-A4 통과
- 스레드: **6** (12는 SMT 경합으로 역효과)

미확정: 상주 RAM 상한은 G-D에 따라 정하지 않고 측정만 한다.

### D7. G-A3S / G-C2a 승인 (C2 선행)

- G-A3S: Notesoop 특징 재현(ONNX FP32 ≥0.99, Q8 ≥0.98) — 측정·보고만 할지, 게이트로 승인할지.
- G-C2a: Q8 특징 사용 시 CER 상대 증가 ≤10% — 승인 여부.
