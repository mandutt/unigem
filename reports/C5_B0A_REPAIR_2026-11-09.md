## 2. CE 정렬

### 이전

```text
logits[:, :-1]  vs  labels[:, 1:]
```

### 이후

```text
logits          vs  labels
```

mT5는 seq2seq 모델이므로 decoder input이 내부에서 shift되어 `logits[t]`가 이미 `labels[t]`를 예측한다.

### 확인값

| 항목 | 값 |
|---|---:|
| built-in `out.loss` | **31.98719596862793** |
| aligned same-position CE | **31.98719596862793** |
| old shifted CE | **33.9515380859375** |
| 차이 | **+1.9643421173095703** |

증거:
- `reports/provenance/C5_b0a/metric_alignment_probe.json`
- `eval/tests/test_c5_b0_metric.py`

### 보존

- B0-A historical JSON/aggregate는 **변경하지 않음**
- B0-A `Δshuffled_copy`는 **as-run / primary-metric-compromised**
- `Δshuffled_full`과 training loss는 `out.loss` 기반이므로 직접 영향은 copy metric에 한정

## 3. Train-mode 대칭

`set_training_mode()` 추가:

- F: `model.eval()`, adapter train, LoRA 없음
- L: `model.eval()`, adapter train, LoRA branch train, wrapped base Linear eval
- `model.training == False`
- `trainable_base_parameters == 0`
- LoRA module count **64**
- LoRA dropout train

### 1-step debug

| arm | first CE | mode |
|---|---:|---|
| frozen | **27.43998146057129** | base eval / adapter train / no LoRA |
| lora | **27.43998146057129** | base eval / adapter+LoRA train |

이전 B0-A에서는 같은 step-0에서 L이 F보다 **+10~12 nats** 높았다. 이번 debug에서는 동일 CE로 시작해 **base dropout 비대칭이 제거됐다.**

- debug artifact: `reports/provenance/C5_b0a/repair_debug.json`
- no gate, no B0-A replacement
