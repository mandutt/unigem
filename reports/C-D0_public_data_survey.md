- 대상: Addendum A §A-8.1, plan v0.5 §9 C-D0
- 범위: C1(이모지), C2(한국어 STT), C4(맞춤법), C5(요약), B1.5 코퍼스 v2
- 원칙: 공개 데이터 우선, 라이선스·접근 요건 명시. **확인 못한 항목은 "미확인"으로 표기**한다.

## 5. 식별자 span (B1.5-2)

- **실제 식별자**는 공개 코드 저장소에서 추출한다(파일 경로, 버전 문자열, 커밋 SHA, 오류 코드, 설정 키, URL, 모델명).
- 후보: Apache-2.0/MIT 저장소(transformers, llama.cpp, vLLM 등). 라이선스상 추출·사용 가능, 출처 표기.
- 800 span 목표: 경로 250, 버전 150, SHA 150, 오류 코드 100, 설정 키 100, URL 50.

## 6. 데이터 등급

- 위 데이터는 전부 **P0**(공개·합성)으로 취급한다. 단, NIKL/AI Hub는 이용약관이 P0와 다를 수 있으므로 **다운로드 전 약관 확인**을 선행한다.
- P1(사용자 미디어·입력 오타)은 이번 조사에 포함하지 않았다.

## 7. 갭과 다음

## 8. 2차 조사 (2026-11-02, Exa) — "공개 데이터 부재" 재검토

### 8.1 C1 UI 스크린샷 — **확보 가능**

| 데이터 | 규모 | 라이선스 | 접근 |
|---|---|---|---|
| **ShowUI_Web** (HF `ZhuOnR/ShowUI_Web`) | 22,000 스크린샷 / 576,000 요소 | **Apache-2.0** | 즉시 |
| **WebUI** (uimodeling) | 400K 웹 UI, Web-7k/70k/350k | 연구용(COPYRIGHT 별도) | 다운로드 스크립트 |
| `ronantakizawa/webui` (HF) | 36,807행, 이미지+bbox+HTML | 구성 소스별 OSS(MIT/Apache/GPL) | 즉시 |
| MultiUI | 7.3M 샘플 | 연구용 | HF |

→ RICO 없이 **ShowUI_Web(Apache-2.0)** 로 C1 착수 가능. 라벨은 요소 bbox를 이모지 후보표와 매칭해 생성.

### 8.2 C5 요약 — **확보 가능 (AI Hub 불필요)**

| 데이터 | 규모 | 라이선스 | 비고 |
|---|---|---|---|
| **XL-Sum (ko subset)** | 1.38GB 전체 중 한국어 tar | **CC BY-NC-SA 4.0** | 비상업, 즉시 |
| Naver News Summary | - | all / rd | 뉴스 요약 |
| KoreaScience Summary | - | all / rd | 과학기술 요약 |
| KorCase_summ | 법률 판결 요약 | 자유 사용(법정 주장 목적 제외) | 도메인 한정 |
| AI Hub 문서요약 | 원문 40만/요약 80만 | AI Hub 약관(내국인 신청) | 선택 |

> **정정:** 1차 조사에서 sae4K를 요약 데이터로 적었으나, 확인 결과 **sae4K는 화행/논항 추출(50K 문장-논항 쌍)** 데이터다(CC BY-SA 4.0). 요약용이 아니다. C5는 **XL-Sum ko**를 주 평가셋으로 사용한다.

→ 메모리형 요약은 여전히 공개 데이터가 없지만, **일반 요약은 XL-Sum ko로 평가 가능**. 메모리 슬롯 보존은 합성 입력으로 보완.

### 8.3 C3 디코더 학습 데이터 — **확보 가능 (라이선스 혼재)**

| 데이터 | 규모 | 라이선스 |
|---|---|---|
| `heegyu/open-korean-instructions` | 375K행(780MB) | 소스별 혼재(KoAlpaca CC-BY-NC-SA 등) |

→ 학습에는 비상업(NC) 데이터가 섞여 있으므로 **연구용으로만** 사용하고, 배포·상업 경로는 분리해야 한다.

### 8.4 C4 맞춤법 — **고품질은 여전히 신청 필요**

| 데이터 | 규모 | 라이선스 | 접근 |
|---|---|---|---|
| AI Hub 인터페이스별 고빈도 오류 교정 | **290,500문장** | AI Hub 약관(내국인) | 신청 |
| NIKL 맞춤법 교정 말뭉치 | 수십만 | NIKL 약관(비상업) | 신청 |
| Standard_Korean_GEC (코드) | - | modified MIT | 코드만 |
| Parkchanjun 테스트셋 | - | **미확인** | 보류 |

→ 공개 즉시 사용 가능한 대규모 교정 코퍼스는 없다. **규칙 합성 + AI Hub 신청(선택)** 조합이 현실적이다.

## 9. 결론 갱신

| 항목 | 이전 판단 | 2차 조사 후 |
|---|---|---|
| C1 UI | RICO 필요 | **ShowUI_Web(Apache-2.0)로 대체 가능** |
| C5 요약 | 공개 데이터 부재 | **XL-Sum ko 등 공개 데이터 존재** |
| C3 디코더 | 데이터 없음 | **공개 instruction 데이터 존재(라이선스 혼재)** |
| C4 맞춤법 | NIKL 신청 필요 | **여전히 신청 필요**, 합성으로 선행 가능 |

**G-DATA(LLM 합성) 승인 필요성**: C4의 문맥 의존 오류와 C5의 메모리형 요약에 한정. C1/C3/C5 일반 요약은 공개 데이터로 대체 가능.
