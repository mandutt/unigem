# B1.5-6 — 길이·접두사 영향 (부분)

- 작성: 2026-11-02
- 대상: Addendum A §A-3.7 B1.5-6
- 상태: **길이 구간 완료, 접두사 미수행**

## 1. 길이 구간별 토큰 복원 정확도

| 구간 | l00 | l04 |
|---|---|---|
| 16–64 | 0.8862 (28,689) | 0.8250 |
| 65–128 | 0.8991 (2,933) | 0.8077 |
| 129–256 | 0.8898 (1,778) | 0.7880 |
| 257–512 | **0.9109** (3,848) | 0.8277 |
| 전체 | 0.8894 | 0.8220 |

- **길이가 길어질수록 하락하지 않는다.** 257–512 구간이 오히려 가장 높다(l00 0.911).
- 129–256이 l04에서 가장 낮지만(0.788) 표본이 1,778토큰으로 작다.
- 해석: 이 코퍼스의 긴 문장은 반복·연결 문장이 많아 토큰 예측이 쉬워진 영향이 있다(구간별 난도 통제 없음).

## 2. 접두사 비교 (미수행)

- 모델 카드의 정확한 접두사 문자열(문서용/질의용)을 확인하지 못해 보류했다.
- 접두사를 넣으면 특징 추출을 3회 다시 해야 하므로(각 ~5분) 별도 실행이 필요하다.

## 3. 판정

- 길이 구간에서는 유의한 하락이 관찰되지 않았다. 접두사는 미측정으로 남긴다.
