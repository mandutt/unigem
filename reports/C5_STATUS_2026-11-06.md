## 5. A2-null

- Reddit/EmbeddingGemma-2 방식: final projection `768×512`의 256d left null space에 intermediate layer 특징을 PCA로 주입
- A2-null은 이를 **text token sequence에 적응**한 exploratory 변형
- D-042의 raw EG2 text hidden 폐기 결정은 유지하며, A2-null은 별도 표현으로 **탐색만** 수행
- F5 제품 채택은 A1과의 val 비교 + 새 gate 결정 전 금지
- 상세: `docs/plan_c5_a2null_v0_1.md`
- **feasibility probe 완료**: W 768×512, rank 512, nullity 256, `max|WᵀP|` 4.29e-06, final projection error 0.0, layer12 PCA256 95.1%, T5 640d external memory PASS (`reports/C5_a2null_probe.md`)
- **pilot complete**: 100/100/100 features, layer12 PCA 94.29%, 20-step adapter loss 15.754→3.741, ~1.95s/step, RSS 3.08GB (`reports/C5_a2null_smoke.md`)
- **pilot generation**: 2건 붕괴(char F1 0.0125, grounded 0/2); 20-step pilot 한계이며 A2-null 판정 아님
- **full extraction**: 완료, **1,293/161/163**, 2.4GB, layer12 PCA 94.10%, `data/wave2c/a2null` (`reports/provenance/C5_a2null/features_meta.json`)
- **full train**: 완료, 1,293 step, **44.1분**, train loss **3.2487**, val loss **3.1196**
- **val 생성**: 5건 char F1 **0.1603**, grounded **0/5**, new slot **0.90** — 반복 붕괴
- **원인 조사에서 확정된 코드 결함**: target tokenizer가 붙인 `<bos>`를 label에 그대로 넣고 `<eos>`를 붙이지 않아, decoder가 첫 토큰으로 `<bos>`를 배우고 정지 토큰을 배우지 못함. **기존 full train 결과는 무효**.
- 수정: label = `content + <eos>`(`<bos>` 제거, padding `-100`). 2-step smoke 통과, 20-step pilot은 여전히 미학습 붕괴(정상).
- **다음**: 수정 label로 full retrain 1 epoch(약 45분) 후 val 5건 재평가. 필요 시 decoder cross-attention LoRA/XA-only.
- **full retrain (EOS 수정)**: 완료, 1,293 step, **42.3분**, train loss **3.2525**, val loss **3.1160**
- **val 생성 (EOS 수정)**: 5건 char F1 **0.2297**, grounded **0/5**, new slot **0.96**, **5/5가 `<eos>` 없이 128토큰 상한까지 생성**
