# C5 B2 layer12 scheduled sampling — on-policy fine-tune (2026-11-08)

## 1. 목적

B2 layer12 r8의 teacher-forced CE는 낮지만 free-running F1/EOS가 낮다.
Gold prefix에 student argmax를 섞는 **scheduled sampling**으로
exposure bias를 직접 완화한다.

- student: B2 layer12 512 + MLP1536, decoder LoRA r8
- init: `b2_layer12_300/adapter_final.pt`
- train 300 / val 100
- 1 epoch, lr 1e-4
- `ss_prob=0.2`: decoder input token의 20%를 student argmax로 교체
- labels는 gold 유지
- test 163 미사용

## 2. 구현

`ce_scheduled`:

1. gold prefix로 teacher-forced forward → student argmax
2. decoder input을 gold prefix로 구성
3. 각 위치를 `p=0.2`로 student argmax로 교체
4. 같은 gold labels에 대해 CE + hidden loss

학습 중 매 step마다 수행한다.

## 3. 학습 결과

| 항목 | 값 |
|---|---:|
| train CE before → after | 1.4011 → **1.1263** |
| val CE before → after | 2.2985 → **2.2356** |
| elapsed | **1,891.6s (31.5분)** |

- layer12 r8(val 2.2983) 대비 **−0.0627**
- teacher-forced fine-tuning이 val CE를 추가로 낮췄다.
- train/val gap은 1.106으로 커졌다.

## 4. Teacher-forced fidelity (target=teacher)

| system | CE | token acc |
|---|---:|---:|
| B2 layer12 r8 | 2.1190 | 56.11% |
| **B2 layer12 ss** | **2.0335** | **57.46%** |

- CE **−0.0855**, token **+1.35%p**
- scheduled sampling이 teacher-forced도 악화시키지 않았다.

## 6. 판정

**SCHEDULED_SAMPLING_F1_GAIN_GROUNDING_LOSS**

- scheduled sampling은 **teacher-forced/val CE/free-running F1/rep4를 모두 개선**
- 그러나 **grounding이 21% → 10%로 붕괴**
- slot preservation은 0.251 → 0.362로 오히려 좋아졌지만,
  **new slot도 0.535 → 0.612로 증가**해 grounded가 낮아졌다.
- “더 유창하지만 더 많이 지어내는” 방향
- 제품 후보 없음; pilot300 fallback; test 163 sealed
