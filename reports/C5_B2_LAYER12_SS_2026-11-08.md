# C5 B2 layer12 scheduled sampling — on-policy fine-tune (2026-11-08)

## 1. 목적

B2 layer12 r8의 teacher-forced CE는 낮지만 free-running F1/EOS가 낮다.
Gold prefix에 student argmax를 섞는 **scheduled sampling**으로
exposure bias를 직접 완화한다.

- student: B2 layer12 512 + MLP1536, decoder LoRA r8
- init: `b2_layer12_300/adapter_final.pt`
- train 300 / val 100
- 1 epoch, lr 1e-4
- `ss_prob=0.2`: decoder input token의 20%를 student argmax로 교체
- labels는 gold 유지
- test 163 미사용

## 2. 구현

`ce_scheduled`:

1. gold prefix로 teacher-forced forward → student argmax
2. decoder input을 gold prefix로 구성
3. 각 위치를 `p=0.2`로 student argmax로 교체
4. 같은 gold labels에 대해 CE + hidden loss

학습 중 매 step마다 수행한다.
