# C5 mT5-small vs UMT5-small layer probe — Stage A (2026-11-08)

## 1. 목적

EG2 layer1~23을 **mT5-small**과 **UMT5-small**의 frozen decoder에 각각 연결해, native cross-attention이 memory를 실제로 사용하는지 screening했다. teacher hidden cosine이 아니라 **decoder CE와 real/zero/shuffled memory ablation**을 측정했다.

## 2. 공통 프로토콜

- EG2 layer1~23, train 5 / val 5, seed 20261108
- adapter: MLP 512→512→512 + LayerNorm, adapter-only
- decoder frozen, encoder bypass via `encoder_outputs`
- 100 steps, lr 1e-3, target max 256
- test 163: **미사용**
- layer0(embedding), layer24(projection) 제외

## 5. 판정

**PARTIAL_MEMORY_USE_NO_CONTENT_SELECTIVITY — both models**

- mT5: real CE vs zero **Δ18.4~19.3**, real vs shuffled **max .189**.

- UMT5: real CE vs zero **Δ3.5~4.0**, real vs shuffled **max .009**.

- 두 모델 모두 **memory의 존재/길이는 사용**하지만, **다른 문서의 memory로 바꿔도 CE가 거의 동일**하다.

- 따라서 layer별 real CE 차이를 **내용 사용성 순위로 해석할 수 없다**. mT5 best layer19, UMT5 best layer12도 이 조건에서는 확정 불가.

- **절대 CE 비교 금지**: mT5 tokenizer 250k vs UMT5 tokenizer 256k, target tokenization이 달라 real CE 값을 직접 비교할 수 없다. 판정은 각 모델 내부의 ablation으로만 한다.

- UMT5가 더 최신·107개 언어·Apache 2.0인 것은 사실이나, **이번 Stage A에서 mT5보다 memory 내용 선택성이 더 좋다는 증거는 없다**. layer 효과도 UMT5가 더 평평하다(real CE range 0.535 vs mT5 0.846).


## 6. 해석과 다음 단계

- **Stage A의 결론은 “어느 layer가 좋다”가 아니라 “frozen decoder + adapter-only로는 내용 선택성을 볼 수 없다”**이다.

- 다음은 **Stage B: decoder LoRA**다. 후보는 각 모델의 real CE 상위권:
  - mT5: layer19, 16, 13, 11, 9
  - UMT5: layer12, 6, 8, 17, 1

- 모델 선택은 Stage B에서 **같은 조건의 content selectivity와 generation**으로 결정한다. UMT5를 최신이라는 이유만으로 채택하지 않는다.

- 5문서/100 step/single seed의 exploratory 결과이며, 제품 후보가 아니다. test 163 sealed.
