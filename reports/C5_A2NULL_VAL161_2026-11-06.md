## 0. 결론

1. **A2-null EOS·LN 모두 제품 후보로 부적합**하다.
   - grounded: **0/161**, **1/161**
   - char F1: **0.1277**, **0.1169** vs A0 **0.6111**
   - EOS: **9.94%**, **6.21%**
   - repeated 4-gram: **0.870**, **0.847**
2. 그러나 **memory가 아무 정보도 없는 것은 아니다.**
   - real vs shuffled ΔNLL: EOS **+0.0580** CI [+0.0520,+0.0640], LN **+0.0582** CI [+0.0518,+0.0643]
   - real vs zero ΔNLL: **+3.20**, **+3.19**
   - 즉 adapter memory에는 문서 특정 신호가 있으나, **free-running decoder가 이를 요약으로 전환하지 못한다.**
3. 이는 “adapter가 문서를 무시한다”기보다 **T5Gemma2 decoder의 생성 적응 부재**에 가깝다. 따라서 다음은 A2 decoder LoRA가 아니라 **A1(native T5Gemma2 encoder + LoRA)**이다.
4. native zero-shot T5Gemma2도 **char F1 0.2333, EOS 1.86%, repeated4 0.8383**으로 심하게 반복한다. A1도 낙관할 수 없으며, smoke/pilot이 필수다.
5. **raw vs seq control은 실행하지 않았다.** full val에서 A2 제품 후보가 이미 기각됐고, A2를 재개할 경우의 필수 조건으로 남긴다.

## 3. Memory ablation (teacher-forced NLL)

각 val 문서에 대해 real memory, 다른 문서의 shuffled memory, zero memory를 같은 target label로 forward했다. `ΔNLL > 0`이면 real memory가 NLL을 낮춘다.

| adapter | real NLL | shuffled NLL | Δ shuffled [95% CI] | positive | Δ zero [95% CI] | positive |
|---|---:|---:|---:|---:|---:|---:|
| EOS | 3.1160 | 3.1740 | **+0.0580** [+0.0520,+0.0640] | 149/161 | **+3.2041** [+3.1409,+3.2656] | 161/161 |
| LN | 3.1288 | 3.1870 | **+0.0582** [+0.0518,+0.0643] | 157/161 | **+3.1913** [+3.1275,+3.2531] | 161/161 |

### 해석

- real memory는 shuffled memory보다 **유의하게** 낮은 NLL을 만든다. adapter가 문서 특정 정보를 어느 정도 사용한다는 뜻이다.
- real vs zero 차이는 크지만, zero memory는 분포 밖 입력이므로 “memory 전체가 유용하다”는 절대 비교로 과해석하지 않는다.
- **중요한 분리**: memory signal은 존재하지만 free-running generation은 붕괴한다. 따라서 병목은 memory 추출만이 아니라 **decoder의 생성 적응**이다.
- 이 결과만으로 null injection의 인과 기여를 확정할 수 없다. raw control(`z_raw = W h`)과 trained raw adapter가 아직 없다.

## 4. 판정

### A2-null

- **제품 후보로 중단**한다.
- 근거:
  - grounded 0/161, 1/161
  - A0 대비 char F1 약 −0.48
  - EOS 6~10%, 반복 0.85~0.87
  - full val에서 val 5보다 더 나빠졌다(char F1 0.2297 → 0.1277)
- **폐기하지는 않는다.** memory-ablation 양성 신호와 raw control 미실행을 기록해 exploratory negative result로 보존한다.

### decoder LoRA

- **지금 하지 않는다.**
- 이유: memory signal은 있으나 generation 붕괴가 decoder 적응 문제인지, adapter 표현 문제인지, null injection 문제인지 아직 분리되지 않았다. A2에 decoder LoRA를 붙이면 A1과 비교할 수 없는 별도 모델이 된다.

### A1

- **다음 주 후보**다.
- native T5Gemma2 encoder-decoder + LoRA(q/k/v/o 우선), base frozen
- clean train 1,293 / val 161
- label은 content+`<eos>`, `-100` padding
- `max_new=448`, 동일 slot 검증기
- smoke → pilot → 2~3 epoch
- test 163은 최종 후보 1회만

A1도 zero-shot baseline이 약하므로 **smoke/pilot 없이 본 학습 금지**다.
