## 3. 해석

### 성과

1. **20문서 overfit 해소** — full val CE 2.634
2. **EOS 60%** — B1d-CE 10%, B2 pilot 40%에서 개선
3. **반복 0.586** — B2 pilot 0.649에서 개선
4. **new-slot 0.634** — pilot 0.921에서 큰 개선
5. **grounded 18%** — 이전 0%에서 회복

### 한계

- grounded 18%는 제품 기준이 아니다.
- new-slot 0.634 — 63%의 요약 슬롯이 source에 없다.
- 평균 292 token — target 평균 209보다 길다.
- A1 native와 F1 격차 0.323.

### 왜 아직 부족한가

- decoder LoRA가 EOS·반복은 잡았지만 **slot grounding**을 직접 학습하지 않았다.
- CE는 gold summary 전체를 학습하지만, **slot 단위 제약**이 없다.
- 1,293 train으로도 EG2 hidden → decoder 요약의 **정보 손실**이 크다.

## 4. 다음 선택

### A. Slot-constrained decoding

- `eval.slot_verify`로 new slot을 차단·repair
- grounded를 제품 수준으로 올릴 수 있음
- 근본 생성 능력 개선은 아님

### B. B2 + slot auxiliary loss

- summary의 slot이 passage에 존재하도록 auxiliary loss
- 예: slot token copy/coverage loss
- 학습 비용 증가

### C. Teacher sequence-level KD

- A1 native pilot300의 grounded 요약을 target으로 사용
- B2 adapter+LoRA를 teacher output에 CE
- 가장 유망하지만 teacher generation 1,293 필요

### D. A1 native 유지

- 현재 **pilot300 fallback** 유지
- bridge는 연구 트랙으로 보류
