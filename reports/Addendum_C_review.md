## 3. 미해결 충돌 (사용자 결정 필요)

### Q1. G-C2a 판정 자격

- 현황: G-C2a는 **D-015에서 게이트로 승인**됐고, 우리는 FLEURS 382클립에서 **PASS**(−0.12%, D-044)로 기록했다.
- Addendum C §C-8.7은 "G-C2a는 승인 대기 제안 게이트이므로 **측정만** 하고 판정으로 쓰지 않는다"고 한다.
- 선택지: (a) D-015 승인을 근거로 **PASS 유지**, (b) **측정 전용**으로 격하하고 CP-C1에서 재승인, (c) 문구를 "PASS(측정), 게이트 승인은 CP-C1"로 병기.
- 권고: **(c)** — 측정 사실과 게이트 자격을 분리 기록.

### Q2. 호스트 배분과 VPS 기동

- 현황: VPS 5대 **전부 stopped**(2026-11-02 사용자 지시). C-14는 vps-1/3/4/5를 배정한다.
- 문제: 기동 비용·시간, 데이터 업로드(수 GB), rate limit. 반면 **데이터·모델이 이미 로컬**에 있고, 판정값은 로컬만 인정된다.
- 선택지: (a) C-5/C-6/C-8은 **로컬** 수행, VPS는 C-9(VLM)만, (b) C-14대로 VPS 기동, (c) 혼합.
- 권고: **(a)** — C-8 CER은 로컬 재현이 이미 가능하고, VPS는 이득 없이 전송 비용만 든다.

### Q3. C-8 비교 시스템

- C-8은 komixv2, whisper-turbo와 비교를 요구한다.
- komixv2·faster-whisper 자산은 `%LOCALAPPDATA%\jev-mem\bench\run-20261024-embedgemma2ko`에 **읽기 전용**으로 존재한다.
- 이 자산을 **읽기 전용 참조**로 사용해도 되는지 확인 필요(운영 자산 보존 원칙).

### Q4. F4 정상문 테스트 확대

- P1 정상 테스트는 **700문장**이다. C-5의 저FPR 진단(0.5% = 3.5문장)은 신뢰구간이 매우 넓다.
- C-6의 G-C4는 "정상 문장 ≥600"이라 형식상 충족하지만, **0.5% 과교정률을 판별하기엔 부족**하다.
- 권고: F4-v2 평가용 정상문을 **2,000문장**으로 확대(규칙 합성·공개 텍스트, P0). 게이트 임계값 변경이 아니라 **표본 확대**다.

### Q5. G-DATA 1단계 승인 시점

- 1단계 3,000쌍, 상한 비용을 명시해 개정안을 제출하면 바로 승인 가능한지. 승인 전 호출은 금지(현재 0회).

## 5. 설계상 확인 사항

1. **C-2 L0/L1/L2**: 논리 일관. L1(pooled 768→프리픽스)은 우리 `sentence_embedding` 출력으로 구현 가능. L2 재개 조건 3개는 상호 배타적이지 않아 **하나라도 충족 시 재개**로 읽힌다(문서 표현 명확).
2. **C-6 F4-v2**: KenLM이 Windows에서 빌드됐으므로 (a) n-gram 점수기는 즉시 가능. 마진은 검증 분할에서만 선택해야 하며, **사전 선언 해시**를 평가 전에 남겨야 한다.
3. **C-7 L1 탭**: 운영 LID 그래프가 `eg2-langidentifier`에 있으며 최적화 여부를 확인해야 한다. 읽기 전용 복사본에서만 작업해야 한다(운영 자산 불변).
4. **C-9 C1**: Qwen3-VL-2B + 사람 라벨링(≥100장)이 필요. 로컬 15.6GB에서 VLM 단독 실행 가능성은 실측 후 결정.
5. **C-11.3**: T5Gemma 2 270M은 이미 보유(1.5GB). FP32/Q8/어휘 pruning 비용 측정은 로컬에서 가능.
6. **AM-7**: 우리가 겪은 세 결함(AUPRC 0.0, npz 반복 인덱싱, val split 부재)이 정확히 AM-7 항목이다. `eval/tests/` 신설은 C-13 후속으로 수용.
