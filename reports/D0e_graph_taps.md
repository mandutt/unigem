# D0-e — A2 Q8 다중 출력·탭 확인 및 G-A3S 보완

- 작성: 2026-11-03
- 대상: Addendum D §D0-e, errata E-3/E-8
- 상태: **완료**
- 호스트: 로컬 (Ryzen 5 7600, CPU)
- 입력: FLEURS ko 앞 20클립, 정적 T=1600 mel (16s 상당)
- 비교: `onnx/eg2_audio_research_fp32_t1600_l12.onnx` vs `onnx/eg2_audio_q8_layers.onnx`

## 1. 그래프 출력

`eg2_audio_q8_layers.onnx`를 실제 ORT로 실행한 결과, 출력은 **14개**다.

| 출력 | shape (T=1600) | 의미 |
|---|---|---|
| `audio_features` | `[N, 512]` (유효 프레임만) | `embed_audio` 1536→512 투영 후 |
| `aud_h_l00`~`aud_h_l11` | `[1, 400, 1024]` 각각 | 12층 hidden (패딩 포함) |
| `aud_out_proj` | `[1, 400, 1536]` | output_proj 후, `embed_audio` **이전** |

- F-D(256d), F-A′(1536d), F-B(11층 1024d), F-C(6/8/10/11층 1024d) 특징을 **모두 이 그래프에서 얻을 수 있다.**
- `audio_features`는 유효 프레임만 평탄화되고, hidden은 패딩 포함 time axis를 유지한다. 비교 시 유효 프레임 수로 잘라야 한다(이번 스크립트에서 처리).

## 2. Q8 hidden parity (20클립, 유효 5,827프레임)

프레임별 cosine(1024d) 분포:

| 층 | mean | min | p1 | p5 | <0.98 비율 |
|---|---|---|---|---|---|
| `aud_h_l06` | 0.999995 | 0.999872 | 0.999980 | 0.999989 | **0%** |
| `aud_h_l08` | 0.999981 | 0.999024 | 0.999888 | 0.999958 | **0%** |
| `aud_h_l10` | 0.999966 | 0.998631 | 0.999696 | 0.999910 | **0%** |
| `aud_h_l11` | 0.999622 | 0.874976 | 0.997307 | 0.999664 | **0.38%** |

- 6/8/10층은 **모든 프레임이 0.9986 이상**이다.
- 11층은 평균 0.99962, p1 0.9973으로 높지만 **0.38% 프레임이 0.98 미만**이다(최소 0.875). 단일 outlier 구간으로 보이며, arm 학습 전에 해당 프레임이 무음/경계인지 확인할 필요가 있다.

## 3. G-A3S — 최종 256d 특징

`aud_out_proj(1536)`에 `embed_audio.embedding_projection.weight[:256]`를 적용하고 L2 정규화한 뒤 비교했다(Notesoop 경로와 동일).

| 지표 | 값 |
|---|---|
| n | 5,827 프레임 |
| mean | **0.999375** |
| min | 0.798303 |
| p1 | **0.995944** |
| p5 | **0.999605** |
| <0.98 비율 | **0.46%** |

- G-A3S의 Q8 기준 **0.98**을 p1/p5는 통과한다.
- **strict minimum 기준으로는 0.46% 프레임이 미달**한다. 기존 G-C2a의 "최소 0.98948"은 30클립 집계 값이며, 프레임 단위로 보면 소수 outlier가 있다.
- 권고: G-A3S는 **p1/p5 기준으로 판정**하고, strict min은 참고로 병기한다. 0.46% outlier가 실제 CTC 프레임에 미치는 영향은 arm 결과로 확인한다.

## 4. 운영 LID 그래프 탭

`onnx/tap/audio_encoder_q8_tap.onnx`의 출력:

```
audio_features, add_8945, linear_134, type_as_108
```

- C-7에서 확보한 3개 탭(11층 FFN 잔차, output_proj 후, 512 투영 직전)만 있다.
- **6/8/10층 탭은 운영 그래프에 노출되어 있지 않다.** 최종 단일 세션 배포에서 6/8/10이 필요하면 그래프 수술을 추가해야 한다.
- D-β 파일럿은 A2 Q8 다중 출력 그래프를 쓰므로 **이 제약과 무관**하다.
