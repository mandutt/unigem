# C5 A1 bare vs prefix val161 + zero-shot `summarize: ` (2026-11-06)

## 목적

full train 전에 두 가지를 확정한다.

1. pilot300 adapter에서 **bare val161**과 **`summarize: ` prefix val161**을 같은 161건으로 비교.
2. base T5Gemma2에 **`summarize: ` prefix**를 주었을 때의 zero-shot val161 기준선을 측정.

test 163은 사용하지 않았다.

## 실행

| 항목 | 값 |
|---|---|
| bare | `runner/c5_a1_eval_batch.py --adapter pilot300_lr2e4_prefix.pt --prefix "" --split val` |
| zero-shot | `runner/c5_zero_shot_t5.py --prefix "summarize: " --split val` |
| batch | A1 8 / zero-shot 4 |
| max_new | 448 |
| val | clean val 161 |
| test | **미사용** |

## 결과

| system | char F1 | grounded | new slot | EOS | repeated4 | summary slots/doc | slot preservation |

| A1 pilot300 **prefix** | **0.657580** | **1.0000** (161/161) | **0** | **1.0000** (161/161) | **0.05535** | **5.199** | **0.45583** |
| A1 pilot300 **bare** | 0.633491 | 0.98758 (159/161) | 3 | 0.99379 (160/161) | 0.06217 | 4.919 | 0.43750 |
| zero-shot `summarize: ` | 0.226113 | 0.71429 | 229 | **0.0000** (0/161) | 0.87181 | 2.261 | 0.06592 |

### Paired bare vs prefix

- prefix − bare: **+0.024089**
- bootstrap 95% CI: **[+0.013186, +0.035089]**
- prefix 우세 **93/161**, bare 우세 **48/161**, 동률 **20/161**
- 해석: **prefix 우위는 노이즈가 아니다.** full train의 입력 계약은 prefix 고정이 맞다.

### Zero-shot

- `summarize: ` zero-shot: char F1 **0.2261**, EOS **0/161**, repeated4 **0.8718**, slot preservation **0.0659**, 76/161 slot-free.
- 기존 zero-shot 0.2333은 한국어 instruction prefix 조건이었다. `summarize: ` 조건도 **0.2261로 사실상 같은 붕괴 수준**이다.
- 즉 base T5Gemma2는 `summarize: `만으로 요약하지 못한다. A1의 개선은 **prefix 문자열이 아니라 LoRA 학습**에서 온다.
- B1d가 base encoder를 teacher로 쓰면 이 **낮은 천장**을 물려받는다. B1d의 목표는 “좋은 요약”이 아니라 **encoder-output 정렬 가능성**으로 제한해야 한다.

## 판정

1. **D2 확정: full train은 prefix 고정.** bare가 더 좋다는 가설은 기각됐다.
2. bare full train arm은 지금 필요 없다. 필요하면 별도 후속.
3. zero-shot `summarize: `는 A1 full train의 blocker가 아니지만, **B1d의 oracle/ceiling**으로 기록한다.
4. `slot preservation`은 prefix 0.456, bare 0.438로 둘 다 A0 0.801보다 낮다. full train 평가에서 **반드시 별도 보고**해야 한다.
5. full train은 아직 시작하지 않았으며, 3-AI Must-fix(checkpoint/eval/selection, epoch reshuffle, rank wiring)가 선행되어야 한다.
