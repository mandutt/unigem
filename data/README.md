# data/ — 데이터 목록과 등급

**데이터 원본은 git에 넣지 않는다.** 이 디렉터리에는 목록·해시·출처·라이선스만 둔다.

| 등급 | 정의 | VPS | 외부 LLM API | 저장 위치 |
|---|---|---|---|---|
| **P0** | 공개 데이터셋, 규칙 기반 합성, 개인정보 없는 합성 | 허용 | 허용 (G-DATA 승인 후) | 어디서나 |
| **P1** | 메모리 저장소 내용, 사용자 미디어·오디오·화면, 실제 입력 오타 | **금지** | **금지** | 로컬 전용 |

규칙:
- 모든 job manifest에 `data_class`를 명시한다. 없으면 실행하지 않는다.
- 평가 세트는 경로 + SHA256으로 고정하고, 한 번 정한 뒤 바꾸지 않는다.
- 합성·pseudo-label 데이터와 평가 세트의 중복(누수)을 검사한다.
- P1 보고서에는 원문 대신 해시·길이·통계만 쓴다.
